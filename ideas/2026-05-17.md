# Project Ideas for 2026-05-17

## 1. Paper Reel
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** [Show HN: TikTok but for scientific papers](https://news.ycombinator.com/item?id=48096842)

### Description
A swipe-style paper discovery app that pulls from the arXiv public API and uses Claude to generate concise, jargon-lite summary cards for each paper. Users scroll through a "For You Page" of CS and AI research, swiping to save or skip papers, and can tap through to the full abstract or PDF. Think Tinder for research papers, but actually useful.

### Key Features
- arXiv API integration filtered by topic (cs.AI, cs.LG, cs.HC, etc.)
- Claude-generated 30-second summary card per paper (plain language, key insight, who should care)
- Save/skip swipe interface with a personal reading list stored in Supabase
- Filter by recency, topic tags, or citation count

### Suggested Tech Stack
React + Vite + Tailwind for the UI, Claude API (claude-haiku-4-5 for cost) for summarization, arXiv REST API (free, no auth), Supabase for saved papers and user preferences

### Why It's Interesting
Staying current with AI research is a constant pain point for CS professors and students alike; this makes paper discovery low-friction and even enjoyable. It is also a tight, portfolio-worthy demo of Claude API + a public data source with a polished consumer UX.

## 2. Spec Forge
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** [Show HN: Replacing spec-driven development with just facts](https://news.ycombinator.com/item?id=48008906) and the "facts-driven development" trend on HN May 2026

### Description
Students write assignment requirements in plain English (a spec), and Spec Forge uses Claude to generate a runnable test suite (pytest, Jest, etc.) directly from that spec. The instructor reviews and approves the generated tests before releasing them to students, who then write code to pass them. This flips the typical workflow: the spec comes first and is machine-verifiable, teaching both TDD and rigorous requirement writing at the same time.

### Key Features
- Spec editor where students (or instructors) write English requirements with structured examples
- Claude-powered test generator that produces pytest or Jest output from the spec
- Instructor review queue to approve, reject, or edit generated tests before publishing
- Assignment runner that executes student code against approved tests and streams pass/fail results in real time
- Diff view showing which spec lines map to which test cases

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask backend, Claude API (claude-sonnet-4-6) for spec-to-test generation, Supabase for assignments and user accounts, Docker sandbox for running student code safely

### Why It's Interesting
Most TDD tools assume developers already know how to write tests; Spec Forge meets students where they are (natural language) and builds the bridge to executable specifications. Instructors get a new lever for autograding that is tied directly to stated requirements rather than hand-written test scripts.

## 3. Algorithm Race
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Gamified CS education trends (sententiagamification.com, 2026) and GitHub trending repos around AI agent evaluation and benchmarking

### Description
A multiplayer web platform where an instructor posts an algorithm challenge (e.g., "implement merge sort," "write a BFS pathfinder") and students submit implementations in Python or JavaScript. The platform benchmarks every submission in an isolated sandbox, then a live leaderboard ranks students on two axes: raw runtime performance AND an AI-judged code quality score. The combination means students cannot win by submitting unreadable micro-optimized code, and they cannot win by submitting clean-but-slow code either.

### Key Features
- Instructor challenge creator: problem statement, starter code, hidden test cases, and time limit
- Isolated execution sandbox (Docker) that measures wall-clock time and memory usage per submission
- Claude-powered code quality scorer that rates readability, naming, structure, and edge-case handling on a 1-10 scale with written feedback
- Live leaderboard with dual axes (speed vs. quality) and replay history of each student's submissions over time
- End-of-round "post-mortem" view showing the top three implementations side by side for class discussion

### Suggested Tech Stack
React + Vite + Tailwind for the leaderboard UI, Flask + Supabase backend, Docker for sandboxed code execution, Claude API (claude-sonnet-4-6) for code quality analysis, WebSockets (via Flask-SocketIO) for live leaderboard updates

### Why It's Interesting
Algorithm courses often optimize only for correctness; Algorithm Race makes performance and code craft simultaneously visible and competitive, turning a dry homework problem into a live event. The dual-metric leaderboard is a concrete, classroom-scale demonstration that "fast" and "clean" are both real engineering values.
