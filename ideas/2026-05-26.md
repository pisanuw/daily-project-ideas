# Project Ideas for 2026-05-26

## 1. Student Portfolio Diff
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** OpenHuman's "reads you first" philosophy (https://www.techtimes.com/articles/316731/20260516/agent-that-reads-you-first-openhuman-tops-github-trending-inverting-playbook.htm) and GitHub Trending growth-tracking tools

### Description
A web tool where CS students paste two snapshots of their work (old code, README, or project description vs. new), and Claude generates a "growth narrative" - a human-readable story of what new skills, patterns, and complexity they have mastered. The output is shareable markdown suitable for portfolio pages or internship applications.

### Key Features
- Side-by-side diff input for old vs. new code or project descriptions
- AI-generated growth story with specific skill tags extracted (e.g., "added async patterns," "adopted component architecture")
- One-click copy of the narrative as clean markdown
- Optional "brutally honest" mode that also surfaces gaps or regressions

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (claude-sonnet-4-6)

### Why It's Interesting
Students consistently struggle to articulate their own growth in cover letters and portfolio blurbs; this converts a raw diff into a compelling narrative with almost no effort.

## 2. Classroom Trend Radar
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** github.com/liyedanpdx/reddit-ai-trends (Reddit AI trend scanner) and "Ask HN: What are you working on? (May 2026)" https://news.ycombinator.com/item?id=48085993

### Description
A professor-facing dashboard that ingests daily signals from HN Show HN posts, GitHub Trending repositories, and r/learnprogramming using a scheduled Flask job, then uses Claude to map each signal to course topics in a professor-supplied syllabus. Professors see a live "what's hot outside the classroom" panel and can pin items to share with students.

### Key Features
- Nightly automated ingestion from HN API, GitHub Trending scrape, and Reddit API
- Claude-powered topic mapping: each trend is tagged against professor's uploaded syllabus
- Pinboard for saving and sharing curated items with students via a public link
- "Curriculum alignment score" showing how closely current course content matches industry buzz

### Suggested Tech Stack
Flask, Supabase (scheduled jobs + data store), Claude API, React, Vite, Tailwind

### Why It's Interesting
Curriculum can lag industry by years; this gives professors a low-effort way to stay current and bring real-world relevance into lectures the same week it happens.

## 3. Synthetic Bias Lab
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** GitHub trending AI fairness repos and Yusuf's interest in AI ethics (https://blog.bytebytego.com/p/top-ai-github-repositories-in-2026)

### Description
An interactive browser-based tool where students design synthetic tabular datasets using configurable demographic bias sliders, then train lightweight binary classifiers in-browser using TensorFlow.js and visualize fairness metrics (disparate impact ratio, equal opportunity difference) side-by-side. Claude generates an "impact report" narrating what each bias pattern would mean in a real hiring or lending scenario.

### Key Features
- Drag-and-drop dataset builder with sliders for base rates, label noise, and demographic skew
- In-browser model training and real-time fairness metric dashboard
- AI-narrated impact report contextualizing metrics in plain language with real-world analogies
- Export trained model weights and dataset for reproducible assignment submissions

### Suggested Tech Stack
React, Vite, Tailwind, TensorFlow.js, Claude API

### Why It's Interesting
Abstract fairness metrics like "disparate impact" become viscerally concrete when students have tuned the bias themselves and watch the numbers shift in real time.
