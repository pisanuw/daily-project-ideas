# Project Ideas for 2026-05-16

## 1. Lecture-to-Flashcard Pipeline
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Reddit and HN discussions on AI study tools in 2026, plus the popularity of spaced-repetition tools like Anki among CS students

### Description
A web app where you paste or upload a lecture transcript, slide text, or assigned reading, and it generates a ready-to-study flashcard deck with question-and-answer pairs plus a concept dependency graph showing how ideas connect. Cards can be studied in-browser with spaced repetition or exported to Anki format (.apkg).

### Key Features
- Paste or upload text/PDF lecture content
- Claude API generates Q&A flashcard pairs with difficulty tags (recall, application, synthesis)
- Interactive concept dependency graph (D3 or React Flow) showing prerequisite relationships
- In-browser study mode with spaced repetition scheduling
- Export to Anki .apkg or plain CSV

### Suggested Tech Stack
React + Vite + Tailwind, Flask backend, Claude API for card generation, Supabase for storing decks, React Flow for concept graph

### Why It's Interesting
Bridges the gap between passive lecture consumption and active recall with zero manual effort, and the concept graph makes hidden prerequisite chains visible to students who are confused about where to start reviewing.

## 2. AI Office Hours Bot
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** DeepTutor (GitHub: HKUDS/DeepTutor) and OpenTutorAI paper (arxiv 2602.07176), plus HN discussions about production AI agents moving into real operational use in May 2026

### Description
A deployable, course-specific Q&A chatbot that a professor feeds with the syllabus, lecture notes, assignments, and past FAQ. Students ask questions through a simple chat interface; the bot answers using RAG over course materials, flags low-confidence answers for professor review, and builds a "confusion heatmap" showing which topics generate the most questions each week.

### Key Features
- Professor uploads course materials (PDF, Markdown, plain text) to build a per-course knowledge base
- Student chat interface with source citations ("from Week 3 slides, slide 14")
- Low-confidence answers automatically queued for professor review with a one-click approve/edit flow
- Weekly confusion heatmap dashboard showing which topics students ask about most
- Supabase vector store (pgvector) for embeddings with per-course namespacing

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask API, Claude API with tool use for retrieval, Supabase (pgvector for embeddings + Postgres for sessions/logs), deployable to Render or Railway

### Why It's Interesting
Actually deployable in a real class with zero infrastructure overhead, and the confusion heatmap gives professors a data-driven signal about where to spend review time, something no current LMS provides.

## 3. Personal Dev RAG Assistant
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** GitHub trending shift toward AI agent orchestration and RAG tooling in May 2026, and the gap between students learning RAG abstractly vs. using it on code they already care about

### Description
Students build their own AI coding assistant that indexes their term-project codebase via embeddings and answers natural-language questions about their own code: "where is the login logic handled?", "why does this function return None?", "what would break if I rename this class?". The assignment teaches RAG architecture, vector search, and AI agent design through a task that is immediately useful to them.

### Key Features
- File watcher that re-indexes changed source files into a local vector store (Chroma or Supabase pgvector)
- Natural-language query interface returning answers with exact file and line citations
- "What would break?" impact analysis using Claude API to reason over the indexed codebase
- Conversation history so students can ask follow-up questions
- Stretch goal: a simple VS Code extension that surfaces answers inline

### Suggested Tech Stack
Python + Flask backend, Claude API (claude-sonnet-4-6) for reasoning, ChromaDB or Supabase pgvector for embeddings, React or plain HTML/JS frontend, instructor-provided evaluation rubric template

### Why It's Interesting
Forces students to learn embeddings, vector search, and agentic retrieval on a codebase they are already emotionally invested in, making the feedback loop immediate and the learning sticky.
