# Project Ideas for 2026-06-08

## 1. Agent Tool Heatmap
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub trending showing explosive growth in AI coding agents (OpenClaw, Cursor, Claude Code) and the need to understand agent behavior patterns — https://blog.bytebytego.com/p/top-ai-github-repositories-in-2026

### Description
A small CLI + web dashboard that reads Claude Code session transcripts or LangGraph trace logs and generates an interactive heatmap of which tools were called most often, in what sequences, and at which steps agents retried or failed. It makes the "black box" of AI agent sessions visually inspectable so you can tune prompts and tool selection.

### Key Features
- Parses Claude Code JSONL transcripts or OpenTelemetry agent traces into a structured event stream
- Renders a color-coded heatmap: tools on one axis, session timeline on the other, with failure/retry markers
- Exportable summary showing top tool chains (e.g., Glob -> Grep -> Read appears 80% of sessions)

### Suggested Tech Stack
Python (transcript parsing), React + Vite + Tailwind (dashboard), Recharts or D3 for heatmap, Supabase optional for persisting multi-session history

### Why It's Interesting
Agent debugging is currently done by scrolling through raw logs; a visual heatmap makes bottlenecks and failure patterns obvious at a glance. Useful both as a personal dev tool and as a portfolio piece demonstrating agentic systems knowledge.

## 2. Grading Transparency Dashboard
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Trend toward AI grading tools (CoGrader, MagicSchool AI, EssayGrader) but the missing student-facing explanation layer — https://cograder.com/content/best-ai-tools-for-teachers/

### Description
A web app where instructors upload a rubric and student submissions, run AI grading via the Claude API, and students can then log in to see a detailed, item-by-item breakdown of why each rubric criterion was scored the way it was, not just a final number. The goal is to turn AI grading from a black box into a learning tool.

### Key Features
- Instructor view: upload rubric as a structured form or paste free-text, batch-grade submissions with one click
- Student view: see their submission alongside each rubric criterion, the AI score, and a 2-3 sentence explanation with a specific quote from their work
- Revision workflow: students can flag a score for instructor review, which queues it in an instructor inbox

### Suggested Tech Stack
React + Vite + Tailwind (frontend), Flask (API layer), Claude API (grading + explanation), Supabase (auth, storage, submissions), Canvas LTI integration optional

### Why It's Interesting
AI grading saves teacher time but students often feel dismissed by a score with no rationale; this bridges that gap by making the AI's reasoning visible and actionable, improving both trust and learning outcomes.

## 3. Tiny Browser Renderer
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Show HN "One Human + One Agent = One Browser From Scratch in 20K LOC" — https://news.ycombinator.com/item?id=46779522

### Description
A structured multi-week project where students build a minimal HTML and CSS rendering engine from scratch, guided by a series of milestones. Each milestone (tokenizer, DOM tree, box model layout, paint) is scaffolded as a test suite students must pass, with an optional AI pair-programming step where students document what the agent helped with versus what they built themselves.

### Key Features
- Milestone 1: tokenize a subset of HTML tags and build a DOM tree
- Milestone 2: implement the CSS box model (width, height, margin, padding, border) and a basic block layout algorithm
- Milestone 3: render the laid-out tree to an HTML canvas or SVG, producing a screenshot comparable to a reference image
- Reflection requirement: a short writeup on which parts were solved with AI assistance and what they learned about parser design and layout algorithms

### Suggested Tech Stack
JavaScript or TypeScript (keeping the stack minimal and browser-native), Jest for milestone test suites, a small Vite dev harness for visual testing, optional Claude API integration for the AI pair-programming reflection step

### Why It's Interesting
Building a browser renderer demystifies one of the most-used pieces of software in existence while teaching parsing, tree traversal, and layout algorithms; adding a structured AI collaboration reflection makes it relevant to how real engineering teams now work.
