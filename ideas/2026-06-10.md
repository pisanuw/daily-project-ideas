# Project Ideas for 2026-06-10

## 1. CS History Clash
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Show HN: Built a daily game where you sort historical events chronologically (https://news.ycombinator.com/item?id=47873966)

### Description
A daily Wordle-style browser game where players sort 5 CS milestones in chronological order: language releases, famous algorithm papers, company founding dates, notable bugs, and hardware breakthroughs. Players get three attempts per day and a shareable result grid, with a new set of events each day.

### Key Features
- Daily curated set of 5 CS/programming history events to order
- Drag-and-drop or click-to-place ordering interface
- Color-coded feedback after each attempt (green = correct position, yellow = wrong position)
- Shareable emoji result grid (like Wordle)
- Local JSON event database with 200+ curated CS milestones

### Suggested Tech Stack
React, Vite, Tailwind CSS, date-fns for daily seeding, localStorage for streak tracking

### Why It's Interesting
CS history is undertaught and this format makes it genuinely fun to learn. It doubles as a great "first day of class" icebreaker and a low-stakes daily habit for students.

## 2. Repo Tour Guide
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** GitHub trending AI education tools 2026 and GitHub Student Developer Pack resources (https://education.github.com/pack)

### Description
A web tool where an instructor pastes a GitHub repo URL and receives an AI-generated interactive guided tour: key files annotated with plain-English explanations, an architecture diagram sketch, suggested reading order for a new contributor, and 3-5 "exploration challenges" tailored to the repo's domain. Instructors can assign a specific repo and have students answer reflection questions based on the tour.

### Key Features
- Fetches repo structure and key files via GitHub API
- Claude API generates plain-English explanations for each important file/directory
- Mermaid.js renders an auto-generated architecture overview diagram
- Instructor mode lets you annotate and publish a saved tour link for the whole class
- Student reflection form with answers auto-graded by rubric via Claude

### Suggested Tech Stack
React, Vite, Tailwind, Flask, GitHub REST API, Claude API, Mermaid.js, Supabase for saved tours

### Why It's Interesting
Reading unfamiliar codebases is one of the hardest skills for CS students, yet it's rarely taught explicitly. This tool scaffolds exactly that skill and makes assigning open-source code analysis practical for any course.

## 3. Multiplayer Code Golf Arena
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Show HN: Gaming Couch - local multiplayer party game platform (https://news.ycombinator.com/item?id=46344573) and competitive programming trends

### Description
Students build a real-time competitive coding platform where participants race to write the shortest correct solution (fewest characters or tokens) to a given problem. A central leaderboard updates live as solutions are submitted and auto-tested. The instructor posts a new problem each round, and students see each other's byte counts shrink in real time.

### Key Features
- Instructor dashboard to post problems with test cases and set round timers
- Monaco editor for in-browser code submission in any language
- Automated test runner validates correctness before recording score
- Live leaderboard with WebSocket updates showing byte count per player
- Post-round "reveal" mode where top solutions are shown and discussed

### Suggested Tech Stack
React, Vite, Tailwind for frontend; Flask + WebSockets (Flask-SocketIO) or Supabase Realtime for live updates; Judge0 or Piston API for sandboxed code execution; Supabase for persistence

### Why It's Interesting
Code golf forces students to deeply understand language idioms and standard library breadth, and the competitive real-time format drives engagement far beyond a standard homework assignment.
