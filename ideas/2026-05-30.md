# Project Ideas for 2026-05-30

## 1. PR Impact Map
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub trending "Understand-Anything" codebase knowledge graph project and discussions about visualizing code change blast radius on HN (May 2026)

### Description
A web tool that takes a GitHub pull request URL, analyzes all changed files, and renders an interactive graph showing which modules are affected, which tests cover the changed code, and the estimated "blast radius" of the change. Claude explains each changed function and its callers in plain English so reviewers understand risk before merging.

### Key Features
- Paste a GitHub PR URL to generate an instant impact graph
- Color-coded nodes: directly changed, transitively affected, and test-covered files
- AI-generated plain-English summary of each changed function and its callers
- Exportable as SVG or shareable link for async code review

### Suggested Tech Stack
React + Vite + Tailwind, Claude API (claude-sonnet-4-6), GitHub REST API, D3.js or React Flow for the graph, Flask or Vercel Edge for the backend

### Why It's Interesting
Code review is often done blind to structural impact; this gives reviewers a spatial understanding of risk in seconds. It is also a natural portfolio piece that combines graph visualization, AI summarization, and real developer workflow pain.

## 2. Agent Permission Dojo
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Show HN: "Continue? Y/N - A 60-second game about AI agent permission fatigue" (Hacker News, May 2026) and Show HN: Statewright visual state machines for AI agents

### Description
A classroom web game where students take turns playing two roles: an AI agent that must request permissions to complete a task, and a human supervisor who approves or denies those requests in real time. Escalating scenarios (web search, file write, external API call, code execution) reveal how authorization models break down. An AI referee scores decisions and explains the security implications of each choice.

### Key Features
- 10+ pre-built scenario packs covering common agent actions (file I/O, API calls, shell commands, database writes)
- Real-time two-player or single-player vs. AI-supervisor mode
- After each round, Claude generates a debrief: what went wrong, which principle was violated (least privilege, human-in-the-loop, etc.)
- Instructor dashboard showing class-wide decision patterns and common mistakes

### Suggested Tech Stack
React + Vite + Tailwind, Supabase (real-time multiplayer state), Claude API for scenario generation and debriefs, Flask backend for game logic

### Why It's Interesting
As AI agents become ubiquitous, understanding authorization and trust boundaries is a core CS literacy skill; turning it into a competitive classroom game makes abstract security concepts viscerally concrete.

## 3. CS Swipe Deck
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Show HN: "TikTok but for scientific papers" (Hacker News, May 2026) and EdTech trends around short-form interactive learning (2026)

### Description
A TikTok-style mobile-first web app where each card presents a CS concept (data structure, algorithm, design pattern, ethics scenario) with a short animated diagram, a 30-word explanation, a runnable code snippet, and one practice question. Students swipe right to save to their review deck, left to skip, and up to dive deeper. Instructors can author topic packs; Claude generates new cards on demand from a concept name.

### Key Features
- Swipe/scroll card UI with animated concept diagrams (CSS or Lottie)
- Runnable in-browser code snippets (Monaco editor, sandboxed iframe execution)
- Spaced repetition review mode for saved cards using a simple SM-2 scheduler
- Instructor authoring panel: type a concept name, Claude generates the card (explanation, diagram description, code snippet, question)
- Topic packs: Algorithms, Data Structures, AI Ethics, System Design, Web Security

### Suggested Tech Stack
React + Vite + Tailwind (mobile-first), Claude API for card generation, Supabase (user decks, progress tracking), Monaco Editor, Framer Motion for swipe animations

### Why It's Interesting
Students already consume short-form content natively; meeting them in that format for CS concepts reduces friction and makes spaced repetition feel like scrolling rather than studying. Instructors get a reusable card-creation tool that cuts prep time dramatically.
