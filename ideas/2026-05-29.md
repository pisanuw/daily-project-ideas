# Project Ideas for 2026-05-29

## 1. Standup Snapshot
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Async standup culture in software teams and the common challenge CS professors face of losing visibility into student project progress mid-sprint

### Description
A lightweight web app for project-based CS courses where students submit a daily 3-field async standup (done, doing, blocked). Claude aggregates entries across all teams, clusters common blockers by theme, and sends the professor a morning digest email highlighting where students are struggling most and which teams look at risk.

### Key Features
- Simple daily check-in form with done/doing/blocked fields
- AI-powered cross-team blocker clustering and severity scoring
- Morning digest email with priority alerts for stuck students
- Instructor dashboard with team progress timelines

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase, Claude API, Resend (email delivery)

### Why It's Interesting
Turns scattered daily check-ins into actionable classroom intelligence without requiring live meetings, giving professors early warning before small blockers become late assignments.

## 2. Agent Blueprint Canvas
**Category:** Teaching Tool
**Complexity:** Multi-week
**Inspired by:** Trending multi-agent frameworks (AutoGen, CrewAI, Mastra) hitting 40k-130k GitHub stars in May 2026 and the difficulty students face reasoning about agent architectures before writing code (https://trendshift.io/topics/ai-agent)

### Description
A drag-and-drop visual editor for designing multi-agent systems. Students place agent nodes on a canvas, define each agent's role, tools, and memory configuration in a side panel, draw directed message-passing edges between agents, and then export working starter code in their framework of choice. Instructors can share read-only diagram URLs for critique during class.

### Key Features
- Visual canvas with draggable agent nodes and labeled directed edges (ReactFlow)
- Per-node config panel: system prompt, tool list, memory type, model choice
- Export to CrewAI YAML, AutoGen Python, or plain Claude API Python
- Shareable read-only diagram URLs for classroom review and grading

### Suggested Tech Stack
React, Xyflow/ReactFlow, Vite, Tailwind, Flask, Claude API, Supabase

### Why It's Interesting
Lowers the barrier to teaching multi-agent architecture by letting students reason visually before touching code, making it easy to critique design choices before implementation bugs appear.

## 3. Paper Debate Pod
**Category:** Classroom Assignment
**Complexity:** 1-2 Weeks
**Inspired by:** "Show HN: TikTok but for scientific papers" (Papel, Hacker News May 2026, https://news.ycombinator.com/item?id=48096842) and NotebookLM-style AI audio discussions

### Description
Students paste an arXiv link or upload a PDF and the app generates a short conversational debate transcript between two AI personas (a skeptic and an advocate) arguing the paper's key claims and limitations. Students listen to the AI debate read aloud, then record a 2-minute audio response taking a side and defending it. Instructors review both the AI debate and the student's spoken response through a grading dashboard.

### Key Features
- arXiv URL or PDF upload with automatic text extraction
- Two-persona debate transcript generation via Claude (skeptic vs. advocate)
- Text-to-speech playback of the generated debate
- In-browser student audio recording and Supabase upload
- Instructor dashboard listing submissions with transcript and audio side by side

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Claude API, Web Speech API (TTS) or ElevenLabs, Supabase, pdf.js

### Why It's Interesting
Transforms passive paper reading into active critical engagement: students must listen to AI-generated disagreement and then defend their own position out loud, building both comprehension and argumentation skills.
