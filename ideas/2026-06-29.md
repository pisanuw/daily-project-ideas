# Project Ideas for 2026-06-29

## 1. Prompt Compression Studio
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub trending June 2026 discussion on LLM context limits and the launch of MiniMax M3's 1M-token context window (https://github.com/trending), plus developer conversation on optimizing API costs

### Description
A web app where you paste an overly long prompt or conversation history and specify a target token budget. Claude analyzes and rewrites the content, preserving the critical instructions and examples while removing redundancy, over-explanation, and filler. A side-by-side diff shows exactly what was cut, a meter shows the token reduction percentage, and an estimated cost savings calculator tells you how much you would save per 1000 API calls at current pricing.

### Key Features
- Paste or type any prompt and set a target token budget with a slider
- Claude-powered compression that preserves intent while eliminating redundancy
- Side-by-side diff highlighting removed and rewritten passages in color
- Token count and cost savings calculator (supports Claude, GPT-4, and Gemini pricing tiers)
- One-click copy of the compressed prompt, with an option to iterate further

### Suggested Tech Stack
React + Vite + Tailwind for the frontend, Claude API (claude-sonnet-4-6) for compression, a lightweight token counting library (tiktoken or Anthropic's token counter), deployed as a Vite static site with a small Flask proxy for API key safety

### Why It's Interesting
Every developer who works with LLMs eventually hits token limits or a surprisingly large invoice -- this tool makes prompt optimization fast and visual, and teaching yourself to write tighter prompts is a genuinely transferable skill.

## 2. Assignment Scaffolder
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** HN "Ask HN: What developer tool do you wish existed in 2026?" (https://news.ycombinator.com/item?id=46345827) and n8n's 2026 AI agent development tools report on AI-powered workflow generation

### Description
An instructor-facing web tool where you describe a programming assignment in plain English (e.g., "Build a binary search tree with insert, delete, and in-order traversal") and Claude generates a complete, ready-to-distribute assignment package: starter code with strategic TODO stubs, a detailed rubric with point breakdowns, autograder-friendly test cases, and a set of tiered hints that progressively reveal the solution path. Everything is exported as a downloadable zip so the instructor can push it directly to a course GitHub org.

### Key Features
- Natural language assignment description form with optional constraints (language, libraries, time limit)
- Claude generates starter code with TODOs at pedagogically useful breakpoints, not trivial gaps
- Rubric output as a structured table (functionality, style, testing, documentation) with point weights
- Progressive hint set (3-5 levels) that guides students without giving away the answer
- Autograder-ready test suite in pytest or Jest, exported alongside the starter code
- One-click zip download for the full assignment package

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask backend for Claude API calls and zip packaging, Claude API (claude-sonnet-4-6) for generation, Supabase to save and reuse assignment templates

### Why It's Interesting
Writing good scaffolded assignments is one of the most time-consuming parts of teaching CS -- a tool that turns a one-sentence description into a publish-ready package could save instructors hours per assignment and dramatically lower the barrier to designing more, better-structured projects.

## 3. Agentic Study Buddy Network
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** GitHub trending repo msitarzewski/agency-agents (a platform of specialized AI agents) and the smolagents library's push toward minimal-abstraction multi-agent runtimes (https://github.com/trending)

### Description
Students build a multi-agent tutoring system where specialized Claude-powered "study buddy" agents each own a topic domain (data structures, algorithms, systems, etc.) and can hand off a student to a peer agent when the conversation shifts domains. A shared Supabase memory store tracks what the student has already mastered so no agent re-explains concepts the student already knows. The student-facing interface is a single chat window that seamlessly transitions between agents, and a dashboard shows the student a graph of their growing knowledge map.

### Key Features
- At least three domain agents (each with its own system prompt and topic expertise) that route conversations based on topic detection
- Handoff protocol where the sending agent writes a context summary that the receiving agent reads before responding
- Shared persistent memory in Supabase recording mastered concepts, common mistakes, and last-session summary per student
- Student-facing knowledge graph visualization (React + a graph library like Cytoscape) that updates after each session
- Instructor panel showing aggregate knowledge gaps across the class by topic node
- Evaluation harness that tests whether the agents correctly identify when to hand off and whether memory is correctly retrieved

### Suggested Tech Stack
Python (FastAPI or Flask) for the agent orchestration backend, Claude API (claude-sonnet-4-6) for each agent, Supabase for shared memory and student records, React + Vite + Tailwind + Cytoscape.js for the frontend and knowledge graph

### Why It's Interesting
Building this project teaches students multi-agent architecture, memory design, and context management all at once in a domain they care about (studying), and the finished product is something they can actually use in their own coursework.
