# Project Ideas for 2026-06-20

## 1. Pixel Sort Canvas
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** ChartGPU (WebGPU-powered charting library at 1M points/60fps, trending on Hacker News June 2026, https://news.ycombinator.com/item?id=48528779) and WebGPU reaching stable status across all major browsers in 2026

### Description
Upload any image and watch classic sorting algorithms (bubble, merge, radix, bitonic) rearrange pixels by brightness, hue, or saturation in real-time, directly on the GPU. The result is a generative art piece unique to your image and algorithm choice — every sort produces a different visual journey from the scrambled state to the final gradient.

### Key Features
- Image upload with pixel extraction into a WebGPU buffer for GPU-side sorting
- Choose algorithm (bubble, merge, radix, bitonic), sort channel (hue, brightness, saturation), and sort direction
- Adjustable speed slider from glacial to instant so you can pause mid-sort for art screenshots
- One-click export of the current canvas state as a PNG

### Suggested Tech Stack
Vanilla JS + WebGPU API (compute shaders in WGSL), Canvas 2D API as a fallback for unsupported browsers

### Why It's Interesting
WebGPU is now stable in Chrome, Firefox, and Safari, making this a zero-dependency browser project that is visually spectacular — it turns a CS1 sorting concept into shareable generative art and gives students instant intuition about how different algorithms traverse data.

## 2. Lesson Plan Autopsy
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Multi-agent critique patterns trending in AI workflows (Hacker News June 2026 discussions on agentic review systems) and broad adoption of AI teaching tools like MagicSchool AI

### Description
A professor pastes or uploads a lesson plan, and four AI agents critique it in parallel — each reading as a different stakeholder: a struggling student, an advanced student, a student with accessibility needs, and a pedagogy researcher. Each agent annotates specific sections with concerns and concrete rewrites, and the UI renders all four viewpoints side-by-side with color-coded highlights.

### Key Features
- Paste or PDF-upload a lesson plan; Claude splits it into annotatable segments
- Four parallel Claude API calls, each with a distinct system prompt establishing persona and critique framework
- Side-by-side annotation view: click any highlighted segment to see all four agents' notes
- Export a consolidated feedback report as PDF or Markdown for revision planning

### Suggested Tech Stack
React + Vite + Tailwind, Flask backend for orchestrating parallel Claude API calls, pdf-parse for PDF ingestion, jsPDF for export

### Why It's Interesting
A single AI reviewer produces generic feedback, but four agents with locked personas surface blind spots that would otherwise only appear in live classrooms — giving professors a structured pre-flight check before the lesson ever runs.

## 3. Behavior Tree Studio
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Resurgence of game AI education on HN and GitHub, Cloudflare Agents Week 2026 (https://www.cloudflare.com/en-au/agents-week), and behavior trees remaining the dominant NPC AI pattern in AAA game production

### Description
Students build a browser-based visual editor for game NPC behavior trees, where they design AI using drag-and-drop composite, decorator, and action nodes drawn on a canvas. An embedded Claude assistant explains what the tree will make the NPC do in plain English, suggests missing edge cases (like "what happens when the NPC's health is zero and the patrol node fires?"), and auto-generates a TypeScript or Python runtime that executes the tree in a tiny test sandbox.

### Key Features
- Visual canvas with draggable nodes: Sequence, Selector, Fallback, Inverter, and leaf actions with configurable parameters
- Claude API integration that reads the current tree JSON and generates a plain-English behavior walkthrough plus edge-case warnings
- Executable runtime export: Claude generates a TypeScript or Python class from the tree that students drop into their own game project
- Test sandbox: a tiny grid-based scene where an NPC runs the exported behavior tree so students see it in action before exporting

### Suggested Tech Stack
React + Vite + Tailwind, React Flow for the visual node editor, Claude API (structured output for tree-to-code generation), Supabase for saving and sharing tree designs

### Why It's Interesting
Behavior trees are the industry standard for game NPC AI but rarely taught in CS courses because the tooling is intimidating — this closes that gap while giving students a visual AI design skill that transfers directly to Unreal Engine, Unity, and game-adjacent robotics.
