# Project Ideas for 2026-06-16

## 1. Prompt A/B Lab
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** The explosion of prompt engineering as a first-class skill in 2026 (Hacker News "What are you working on?" June 2026 threads, discussions around agentic coding workflows)

### Description
A minimal web app where you write two versions of an AI prompt, fire them at the same model simultaneously, and see the outputs side by side with inline diff highlighting showing exactly where they diverge. Experiment history is saved to localStorage so you can compare across sessions.

### Key Features
- Dual-pane editor: write Prompt A and Prompt B, choose model and temperature
- Side-by-side output view with character-level diff highlighting
- Experiment history saved locally (prompt pairs + outputs + timestamps)
- One-click copy of winning prompt to clipboard

### Suggested Tech Stack
React + Vite, Tailwind CSS, Claude API or Gemini API, diff2html or custom diff logic, localStorage

### Why It's Interesting
Prompt engineering is still mostly trial-and-error in a single chat window; this makes it systematic and visual, which is exactly the kind of sharp single-purpose tool that shows strong product thinking in a portfolio.

## 2. Exit Ticket Bot
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** iClicker's real-time classroom feedback loops and Deck.Toys adaptive learning paths (edcafe.ai roundup of AI classroom tools, June 2026)

### Description
A web dashboard where an instructor pastes lecture notes or slide text, and the tool instantly generates 3 short quiz questions. A QR code appears on screen; students scan it on their phones and answer in under 2 minutes. The teacher sees a live results dashboard plus an AI summary identifying which concepts the class is weakest on, ready to use at the start of the next lecture.

### Key Features
- AI question generation from pasted lecture text (multiple-choice + short-answer)
- Shareable QR code that opens a zero-install mobile answer form
- Real-time answer aggregation via Supabase realtime subscriptions
- Post-class concept weakness summary generated by Claude

### Suggested Tech Stack
React + Vite, Tailwind CSS, Supabase (realtime + database), Claude API, qrcode.react

### Why It's Interesting
Closing the feedback loop after class normally requires clicker hardware or a third-party subscription; this replaces both with a free self-hosted tool while adding AI-powered diagnosis of the specific concepts that need revisiting.

## 3. AI Podcast Studio
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** VoxCPM2 (tokenizer-free multilingual TTS) trending on GitHub in June 2026, and the broader rise of AI-generated audio content as a learning medium

### Description
Students build a web app that takes a CS topic chosen by the user and generates a realistic 5-10 minute podcast episode as a scripted dialogue between two AI personas: a curious beginner and a pragmatic senior developer. A TTS API converts the script to audio, which can be played in-browser or downloaded as an MP3.

### Key Features
- Topic picker with difficulty slider (intro / intermediate / advanced)
- LLM generates a structured two-voice dialogue script with natural transitions
- TTS synthesis of each voice (distinct voices for each persona)
- In-browser audio player with transcript toggle, plus MP3 download

### Suggested Tech Stack
React + Vite, Flask or FastAPI backend, Claude API (script generation), ElevenLabs API or browser Web Speech API (TTS), ffmpeg (audio merging)

### Why It's Interesting
The project teaches an end-to-end AI pipeline (LLM prompt chaining, TTS, audio I/O, UX) and produces a genuinely useful artifact: an on-demand audio explainer students can listen to while commuting, with real production-quality engineering challenges around latency and voice consistency.
