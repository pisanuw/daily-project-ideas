# Project Ideas for 2026-06-07

## 1. Vibe Code Fingerprinter
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** r/SideProject discussions in 2026 about "vibe coding" with AI app builders (Bolt, Lovable, Emergent) and the question of how to tell AI-generated code from human-written code

### Description
A React single-page app that takes any public GitHub repository URL and analyzes commit metadata, file churn patterns, and code structure to generate a "vibe score" estimating AI involvement. It visualizes metrics like commit size variance, lines-changed-per-commit distribution, and code complexity consistency in a fun shareable dashboard. The result is a provocative, conversation-starting tool that surfaces real signals about how a repo was built.

### Key Features
- Paste a GitHub repo URL and get an instant vibe score (0-100)
- Visual breakdown: commit size histogram, churn heatmap, complexity variance chart
- Shareable score card image for Twitter/LinkedIn
- Optional: Claude API call to spot AI-typical code patterns in a sample file

### Suggested Tech Stack
React, Vite, Tailwind, GitHub REST API (no auth for public repos), Recharts for visualization, optionally Claude API for code pattern analysis

### Why It's Interesting
The vibe coding debate is everywhere right now and this turns it into a concrete, visual tool. It is portfolio-worthy precisely because it is opinionated and slightly controversial, which drives sharing.

## 2. Agent Workflow Diff
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Show HN: "Git for AI Agents" (https://news.ycombinator.com/item?id=48063548) and the idea of applying version control semantics to AI agent interactions

### Description
A classroom tool that applies code-review thinking to AI agent assignments. The instructor posts a multi-step agent task (for example, "research and summarize this paper, then draft a response email"). Students submit their agent solution as a structured log of tool calls, prompts, and outputs. The tool renders two student solutions side-by-side with a diff view highlighting different tool-calling strategies, prompt choices, and intermediate outputs, making agent design decisions discussable in class.

### Key Features
- Instructor dashboard for posting tasks and managing submissions
- Structured submission format (JSON) capturing prompts, tool calls, and outputs
- Side-by-side diff viewer comparing two submissions, color-coded by step type
- Inline comment threads for instructor and peer feedback on specific agent steps
- Leaderboard showing which solutions scored best on a rubric

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase (auth + storage), Claude API for automated rubric scoring

### Why It's Interesting
Most AI assignments are graded as a black box. This makes the process of designing an agent solution as visible and reviewable as a pull request, which is exactly the skill students need in a world of production agent systems.

## 3. Personal MCP Context Server
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** OpenClaw's viral local AI integration hub (210k+ GitHub stars) and the Anthropic Claude Agent SDK release in June 2026

### Description
Students build a personal MCP (Model Context Protocol) server in Python that indexes their own course materials, PDFs, and notes into a local vector store and exposes semantic search and retrieval as MCP tools. Once wired into Claude Desktop or any MCP-capable client, they have a working "personal study assistant" that knows their exact course content. The assignment teaches embeddings, MCP protocol design, and privacy-first AI architecture in one cohesive project.

### Key Features
- Ingestion pipeline: scan a folder, chunk PDFs and text files, embed with a local model or API
- MCP tool definitions: `search_notes(query)`, `get_document(id)`, `list_sources()`
- Claude Desktop integration: plug in the MCP config and chat with your own notes
- Stretch goal: add a `web_fetch_and_save(url)` tool that imports web pages into the index
- Evaluation rubric: correctness of MCP tool schemas, retrieval quality on 10 test queries, latency

### Suggested Tech Stack
Python, FastMCP or the official MCP Python SDK, SQLite with sqlite-vec or ChromaDB for vector storage, sentence-transformers or OpenAI/Claude API for embeddings, Claude Desktop for testing

### Why It's Interesting
Students ship something they will actually use every day, and the project naturally teaches the full stack of modern AI engineering: data ingestion, embeddings, tool schemas, and agent integration, all without any cloud dependency.
