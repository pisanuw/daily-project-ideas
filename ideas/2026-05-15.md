# Project Ideas for 2026-05-15

## 1. Commit Narrator
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub trending repositories (May 2026) showing demand for developer storytelling tools, and r/SideProject posts about tools that turn raw data into shareable narratives

### Description
A web app that takes a public GitHub repository URL, fetches its commit history via the GitHub API, and uses Claude to generate a readable narrative of how the project evolved: key pivots, refactor moments, velocity shifts, and the arc from first commit to current state. The output is a shareable "project story" page.

### Key Features
- GitHub URL input with OAuth or public-repo token-free access
- AI-generated narrative with timeline anchors (milestones, big rewrites, contributor inflection points)
- Visual commit heatmap alongside the prose story
- One-click shareable link stored in Supabase

### Suggested Tech Stack
React + Vite + Tailwind, Flask backend, Claude API (claude-sonnet-4-6), GitHub REST API, Supabase for storing generated stories

### Why It's Interesting
Every open-source project has a human story buried in its commits; this tool surfaces it in seconds and is immediately portfolio-worthy for both the builder and the repo owner being analyzed.

## 2. Agent Memory Lab
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** r/AI_Agents (May 2026) discussions identifying agent memory as the top pain point for practitioners, and DeepTutor's multi-modal learning approach showing demand for hands-on AI concept exploration

### Description
A classroom dashboard where students chat with an AI agent while watching a live visualization of its memory: which past messages are semantically similar to the current query, how relevance scores shift, and what gets "pushed out" as the context window fills. Instructors can inject or wipe memory to demonstrate retrieval failures and hallucination conditions.

### Key Features
- Split-screen: chat panel on the left, live D3.js memory graph on the right
- Semantic similarity scores shown as edge weights between stored chunks and the current query
- Instructor mode: inject misleading memory, clear context, or freeze state for class discussion
- Export session replay as an annotated walkthrough for homework review

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask + Supabase with pgvector for embeddings, Claude API, D3.js or vis-network for the graph

### Why It's Interesting
AI memory is invisible by default; making it visible turns an abstract concept into something students can poke and break, which is the fastest path to genuine understanding.

## 3. Agentic Game Playtester
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Hacker News post "Letting AI play my game - building an agentic test harness to help play-testing" (https://news.ycombinator.com/item?id=47947525) and 2026 AI game dev tool trends

### Description
Students build two things in tandem: a simple browser game in Phaser.js and an AI agent that autonomously plays it by reading game state from a JavaScript API the student exposes. The agent generates a structured report covering difficulty curves, stuck points, exploitable edge cases, and simulated novice-vs-expert player personas.

### Key Features
- Game state API contract students must implement (position, health, score, event log)
- Agent runner that loops actions (move, jump, interact) and observes outcomes
- Automated playtest report with difficulty curve chart, bug list, and suggested balance tweaks
- Multi-persona mode: the same agent plays as "cautious explorer" vs "speedrunner" to surface different issues

### Suggested Tech Stack
Phaser.js for the game, Claude API or Gemini API for the agent reasoning loop, React dashboard for the report, Node.js or Flask as the game-state relay server

### Why It's Interesting
The assignment teaches game design, AI agent architecture, and API contract design simultaneously, and students end up with two portfolio pieces (the game and the tester) instead of one.
