# Project Ideas for 2026-05-18

## 1. Ethics Diff
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Show HN "Replacing spec-driven development with just facts" (https://news.ycombinator.com/item?id=48008906) and growing AI ethics tooling gap

### Description
A web tool where you paste two versions of code (or two LLM prompts) side-by-side and Claude analyzes the ethical differences between them: privacy implications, potential bias, accessibility gaps, and data handling changes. Output looks like a code diff, but for ethical risk rather than syntax.

### Key Features
- Side-by-side input for two code snippets or prompts
- Claude API analysis highlighting privacy, bias, accessibility, and environmental cost deltas
- Diff-style UI with color-coded risk levels (green/yellow/red) per ethical dimension
- Shareable report URL for classroom discussion or code review

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (claude-sonnet-4-6), Flask for the analysis endpoint

### Why It's Interesting
AI ethics is taught abstractly; this makes it concrete and comparative. A professor can paste two real-world code samples and immediately ground a discussion in observable differences rather than hypotheticals.

## 2. MCP Playground
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** "Show HN: Git for AI Agents" (https://news.ycombinator.com/item?id=48063548) and MCP becoming the dominant standard for AI tool-use (https://www.stackone.com/blog/ai-agent-tools-landscape-2026/)

### Description
A browser-based sandbox where students write a minimal MCP server (Python or JS), connect it to a Claude-powered chat interface, and watch Claude invoke their tool in real time. A live trace panel shows every tool-call request and response as a collapsible JSON tree, making the agent's reasoning transparent.

### Key Features
- In-browser code editor (Monaco) for writing a simple MCP server scaffold
- One-click "Connect" to spin up the server locally and wire it to Claude
- Live tool-call trace panel showing request schema, Claude's invocation, and the response
- Library of starter templates (weather API, calculator, CSV reader) for quick onboarding

### Suggested Tech Stack
React, Vite, Tailwind, Monaco Editor, Flask (MCP server runner), Claude API, Supabase (save sessions)

### Why It's Interesting
MCP is rapidly becoming the standard plumbing for AI agent tool-use, but it is a black box for most students. This makes the full request-response cycle visible and editable, turning tool-use from magic into mechanics.

## 3. Replay Board
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** "Show HN: TikTok but for scientific papers" (https://news.ycombinator.com/item?id=48096842) and game-replay culture applied to CS education

### Description
A collaborative platform where students submit short screen recordings of their coding sessions (5-15 minutes, solving a given problem), then classmates can annotate specific timestamps with questions or feedback, similar to how sports analysts mark up game film. An AI layer auto-suggests timestamps worth discussing based on detected hesitations, backtracking, or long pauses.

### Key Features
- Video upload and timestamped annotation (text or emoji reactions)
- AI-powered "moment detection" that flags interesting timestamps (long pause, repeated undo, sudden refactor)
- Instructor dashboard to assign a problem, view all submissions, and highlight standout moments for class discussion
- Privacy controls so students can choose who sees their replay

### Suggested Tech Stack
React, Vite, Tailwind, Supabase Storage (video), Supabase Realtime (live annotations), Flask, Claude API (moment analysis), ffmpeg (server-side processing)

### Why It's Interesting
Problem-solving process is normally invisible after submission. Replay Board surfaces the struggle, the backtracking, and the creative leaps, giving instructors rich material for discussing how to think, not just what to produce.
