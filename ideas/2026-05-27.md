# Project Ideas for 2026-05-27

## 1. Algorithm Cinema
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** "Show HN: TikTok but for scientific papers" (https://news.ycombinator.com/item?id=48096842) — the swipe-and-watch format for dense content, applied to algorithm learning

### Description
A React app where users paste pseudocode or pick a named algorithm and instantly get a step-by-step animated visualization with AI-generated narration. Each "frame" highlights the active element, annotates the current operation, and plays through at adjustable speed — like a movie for your algorithm.

### Key Features
- Paste code or choose from a catalog (sorting, graph traversal, DP, backtracking)
- Animated frame-by-frame playback with pause, rewind, and speed control
- Claude-generated narration for each step in plain English
- Shareable links to specific algorithm animations

### Suggested Tech Stack
React, Vite, Tailwind, Framer Motion (swipe/animation), D3.js (data structure rendering), Claude API (step narration)

### Why It's Interesting
Visual algorithm animation tools exist, but none let you paste arbitrary code and get an explanation-with-animation instantly — this bridges the gap between "show me the code" and "show me it running."

## 2. Behavior Facts Checker
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** "Show HN: Replacing spec-driven development with just facts" (https://news.ycombinator.com/item?id=48008906) — the idea that plain-language facts are more approachable than formal specs

### Description
A classroom tool where students write plain-English "behavioral facts" about their code (e.g., "returns an empty list when the input is empty", "never modifies the original array") and an AI agent generates and runs targeted tests to verify each fact against their actual implementation. Results show which facts passed, which failed, and why.

### Key Features
- Students submit code + a bulleted list of plain-English behavioral claims
- AI generates and executes test cases for each claim automatically
- Color-coded fact-by-fact report with failing test output shown inline
- Instructor view aggregates which facts the whole class got wrong

### Suggested Tech Stack
React, Vite, Tailwind (frontend), Flask (backend + code execution sandbox), Claude API (fact-to-test generation), Supabase (submission storage)

### Why It's Interesting
It teaches students to think about software behavior before writing code, lowers the barrier to writing specs, and gives instructors data on where misconceptions cluster — all without requiring students to learn a formal testing framework first.

## 3. API Cost Compass
**Category:** Student Resource
**Complexity:** Multi-week
**Inspired by:** GitHub trending showing explosion of multi-provider LLM agent projects (https://ossinsight.io/trending/ai) — students regularly hit surprise bills when building AI apps

### Description
A web app where developers and students enter a prompt template, expected daily request volume, and context/output size, then see projected monthly costs across major LLM providers side by side (Anthropic, OpenAI, Gemini, Mistral). It also models the savings from prompt caching and suggests cheaper model tiers that would handle the workload.

### Key Features
- Visual cost comparison table across providers and model tiers
- Prompt caching savings estimator (especially for Anthropic/OpenAI)
- Save and name prompt templates for reuse across projects
- "Switch to X" calculator showing exact savings if migrating providers

### Suggested Tech Stack
React, Vite, Tailwind (frontend), Flask (pricing logic, provider API schema parsing), Supabase (saved templates), Chart.js or Recharts (cost graphs)

### Why It's Interesting
Students building AI course projects routinely underestimate API costs; this tool makes cost a first-class design constraint, teaching real-world production thinking alongside the AI skills.
