# Project Ideas for 2026-05-31

## 1. Honest Commit Checker
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub trending developer tools focus; the widespread frustration with vague commit messages like "fix stuff" or "misc updates"

### Description
A CLI tool and pre-commit hook that reads your staged git diff and proposed commit message, then uses Claude to score how accurately the message describes the actual changes. It catches misleading or lazy commit messages before they land in the history and suggests three ranked alternatives.

### Key Features
- Reads staged diff and draft commit message, scores accuracy 1-10
- Generates three alternative commit messages ordered by specificity
- Configurable strictness levels (warn vs. block the commit)
- Optional GitHub Actions mode that checks PR titles against the diff

### Suggested Tech Stack
Python, Claude API, pre-commit framework, GitHub Actions YAML

### Why It's Interesting
Good commit hygiene is hard to teach by lecture alone; having a tool that gives instant, diff-aware feedback makes the lesson visceral and practical for students and working devs alike.

## 2. Pre-Lecture Q&A Predictor
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Hacker News "Ask HN: What are you working on? (May 2026)" threads discussing AI tools that reduce cognitive load for knowledge workers

### Description
A web app where professors upload lecture slides or a PDF and receive a ranked list of the top questions students are likely to ask, complete with draft answers and a confidence score per question. Professors can edit, approve, or discard each pair, then export the FAQ to Canvas LMS, a Slack channel, or a shareable public page.

### Key Features
- Upload PDF/PPTX; Claude extracts concepts and predicts student confusion points
- Confidence score per question (based on concept density and prerequisite assumptions)
- Inline editing of draft answers before publishing
- One-click export to Canvas announcement, Slack, or static HTML FAQ

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Claude API, Supabase (for saving decks across sessions)

### Why It's Interesting
It flips the usual AI tutoring direction: instead of helping students after they're confused, it helps professors get ahead of confusion before class even starts.

## 3. Tiny Transformer Workshop
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** GitHub trending "Build Your Own X" (500k+ stars) and the 2026 surge in courses teaching LLM internals from first principles

### Description
A scaffolded multi-week project where students implement a GPT-style transformer from scratch in Python/PyTorch, then visualize its internals (attention heads, token embeddings, loss curves) through a React dashboard. Each week unlocks a new layer: tokenization, embedding, self-attention, MLP blocks, and finally training on a small corpus like Shakespeare or a subset of Python docs.

### Key Features
- Week-by-week starter code with autograded pytest suites at each milestone
- React + D3.js visualization dashboard showing live attention heat maps and generation step-by-step
- Flask endpoint to serve the student-trained model for a chat demo
- Final deliverable: a working mini-LLM that can continue short text prompts

### Suggested Tech Stack
Python, PyTorch, Flask, React, Vite, D3.js, pytest

### Why It's Interesting
Building a transformer from scratch demystifies what LLMs actually do far more effectively than any lecture; students graduate with an artifact they can genuinely show off.
