# Project Ideas for 2026-05-23

## 1. PR Narrator
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Hacker News discussions on code review culture and tooling (https://news.ycombinator.com/show)

### Description
Paste a GitHub PR URL or raw diff and get a structured, human-readable narrative of what changed and why. The app produces a review-ready summary with sections covering the intent of the change, risk areas to scrutinize, and a suggested review checklist, making code review faster and less error-prone.

### Key Features
- Accepts GitHub PR URL or pasted diff text
- Generates structured narrative: intent, what changed, risk areas, review checklist
- One-click copy of the summary as a formatted PR comment
- Optional "diff size warning" that flags PRs too large to review effectively

### Suggested Tech Stack
React + Tailwind (frontend), Claude API for narrative generation, optional Vite for fast local dev; no backend required for the basic version

### Why It's Interesting
Code review is a skill rarely taught explicitly in CS programs, and AI-generated summaries can scaffold that skill for junior developers and students. It's immediately useful and highly shareable.

## 2. AI Pair Logger
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Growing debate on AI use in academic settings and GitHub trending AI productivity repos (https://ossinsight.io/trending/ai)

### Description
A lightweight web app where students log each AI-assisted coding session: what they prompted, what the AI generated, what they kept versus what they modified, and how long the session took. Professors get an aggregate class dashboard showing AI usage patterns, helping them calibrate assignments and academic integrity policies with data rather than guesswork.

### Key Features
- Student-facing session log form (prompt, output summary, keep/modify/discard, time spent)
- Supabase backend for real-time data storage per course
- Professor dashboard with heatmaps and filters by assignment, student, and AI tool used
- Weekly "AI reflection" prompt generated by Claude API based on each student's own logs

### Suggested Tech Stack
React + Tailwind (frontend), Supabase (auth + database), Flask (thin API layer), Claude API for reflection generation

### Why It's Interesting
No one has good data on how students actually use AI in CS coursework; this tool generates that data while encouraging metacognition, turning AI use from a policy problem into a learning opportunity.

## 3. Prompt Injection Dojo
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Trending AI security research and the awesome-ai-agents-2026 repository highlighting adversarial agent patterns (https://github.com/caramaschiHG/awesome-ai-agents-2026)

### Description
A competitive web platform where students practice offensive and defensive prompt engineering in structured rounds. Red-team students craft adversarial prompts targeting a sandboxed LLM with a defined goal (extract a secret, change behavior); blue-team students build system prompt defenses that resist those attacks. The platform automates scoring each round and maintains a class leaderboard.

### Key Features
- Configurable challenge scenarios with hidden secrets and defined attack goals
- Round-based matchmaking: red team submits attack prompts, blue team's defense is tested automatically
- Claude API sandbox that runs attacks against defenses and reports outcomes
- Leaderboard with per-round breakdowns and an "explain the outcome" post-mortem view
- Professor control panel to create new scenarios and set difficulty parameters

### Suggested Tech Stack
Flask (backend, round orchestration), Claude API (sandboxed attack/defense evaluation), React + Tailwind (frontend), Supabase (leaderboard + round history)

### Why It's Interesting
Prompt injection is one of the most critical and underappreciated AI security risks; building both sides of the attack/defense dynamic gives students intuition no lecture alone can provide, and the competitive format makes it genuinely fun.
