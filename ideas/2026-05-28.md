# Project Ideas for 2026-05-28

## 1. Context Primer
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** OpenHuman (GitHub trending, May 2026) — an agent that reads user context before the first prompt, inverting the usual "blank slate" chatbot model

### Description
A single-page web app where you paste your resume, course syllabus, or project README and it generates a compact "AI context card" — a structured paragraph describing your background, current goals, and known gaps. You copy this card to the top of any AI conversation so the model immediately understands your level without you re-explaining from scratch every session.

### Key Features
- Paste or upload any plain-text document (syllabus, resume, portfolio blurb)
- Claude API extracts a concise context card in a consistent structured format
- One-click copy to clipboard, optionally stored in browser localStorage for quick reuse
- Diff view when you update the source document to see what changed in your context card

### Suggested Tech Stack
React + Vite + Tailwind, Claude API (claude-sonnet-4-6), no backend needed

### Why It's Interesting
Every student and developer re-explains their background to AI tools dozens of times a week; this turns that friction into a reusable artifact. It also teaches users to think explicitly about their own knowledge state, which is a metacognitive skill worth building.

## 2. Swipe to Ship
**Category:** Classroom Assignment
**Complexity:** 1-2 Weeks
**Inspired by:** "Show HN: TikTok but for scientific papers" (Hacker News, May 2026) — the swipe-card pattern applied to discovery and curation

### Description
A swipe-card interface (Tinder-style) for CS students to discover beginner-friendly open-source GitHub issues they could actually contribute to. Each card renders the issue title, repo context, difficulty estimate, and an AI-generated "why this matters" explanation in plain language. Swipe right to save to a personal contribution queue, left to skip, up to bookmark for later.

### Key Features
- Pulls "good first issue" and "help wanted" issues from GitHub API across curated repos
- Claude API rewrites each issue in plain language with a difficulty rating and suggested first steps
- Personal queue view showing saved issues with progress tracking (not started / in progress / submitted PR)
- Filter by language, topic tag, or estimated time commitment

### Suggested Tech Stack
React + Vite + Tailwind, GitHub REST API, Claude API, Supabase (user queues and progress), Flask or Vercel Edge for the AI rewriting step

### Why It's Interesting
Open-source contribution is one of the best resume builders for CS students but the discovery problem is real — most students never find an issue that feels approachable. This lowers the activation energy to near zero while teaching students to read real production code.

## 3. Live Coding Observatory
**Category:** Teaching Tool
**Complexity:** Multi-week
**Inspired by:** MemOS (GitHub trending, May 2026) — persistent memory + cross-session pattern tracking for AI agents; applied here to human coding behavior instead

### Description
A professor-facing dashboard where students opt in to share editor telemetry (keystrokes, file saves, error events) during lab sessions. An AI agent accumulates a persistent memory of each student's coding patterns across sessions and surfaces a weekly "coding health report" per student — highlighting recurring habits like skipping edge cases, copy-pasting without adapting, or never running tests before submitting.

### Key Features
- Lightweight VS Code extension students install to stream anonymized telemetry (no source code, only event metadata)
- Flask + Supabase backend stores per-student event streams with session boundaries
- Claude API summarizes patterns weekly per student into a structured report with specific examples
- Professor dashboard shows class-wide heat maps (e.g., "60% of students never run tests mid-session") plus drill-down per student
- Students can also see their own report to self-reflect before 1-on-1 office hours

### Suggested Tech Stack
VS Code Extension API (TypeScript), Flask + Supabase (backend + storage), Claude API, React + Tailwind (dashboard), WebSocket for live event streaming

### Why It's Interesting
Most professors only see finished code, never the process; this makes the invisible visible without invading privacy (no source code is transmitted). It turns formative assessment into something that actually scales to large classes.
