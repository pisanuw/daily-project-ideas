# Project Ideas for 2026-06-19

## 1. Game Palette Inspector
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Accessibility trends in game dev communities and the gap between web WCAG tooling and game color-accessibility tooling (filamentgames.com game-based learning blog, June 2026)

### Description
A web tool where game developers upload a screenshot or paste hex color values from their game, and it checks every color pair against WCAG contrast ratios, simulates how the palette appears under eight types of colorblindness (deuteranopia, protanopia, tritanopia, and more), and generates an accessibility report with suggested replacement colors that preserve the visual style.

### Key Features
- Drag-and-drop screenshot upload or hex color palette entry
- Side-by-side colorblindness simulation (8 filter types) using CSS/Canvas filters
- WCAG AA/AAA contrast ratio matrix for all color pairs with pass/fail indicators
- One-click suggested replacement palette that meets accessibility thresholds
- Exportable PDF/PNG report for design handoff

### Suggested Tech Stack
React, Vite, Tailwind, color-blind npm library, chroma-js for color math, html2canvas for PDF export

### Why It's Interesting
Roughly 8% of men are colorblind, yet most game dev color-accessibility tooling focuses on web UIs, not game sprites and palettes. This fills a real gap and is immediately useful to any indie game developer.

## 2. Teach-Back Video Studio
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Curipod and EdCafe AI's 2026 roundup of AI student-engagement tools showing teach-back (explain-it-back) dramatically improves retention

### Description
Students record short browser-based "teach-back" clips explaining a concept they just learned, and an AI analyzes the transcript for conceptual accuracy, clarity, and misconceptions. Teachers receive a per-concept confidence heat map showing which ideas the class can confidently articulate and which ones reveal systematic gaps, turning a grading-heavy technique into a scalable formative assessment.

### Key Features
- In-browser recording via MediaRecorder API, no installs required
- AI transcript analysis scoring accuracy, clarity, and gap identification (Claude API)
- Per-concept class heat map dashboard for the instructor
- Peer-view mode: share approved clips with classmates as study resources
- LMS-compatible CSV export of scores and transcripts

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase (auth + storage), Claude API (transcript analysis), MediaRecorder API

### Why It's Interesting
Teach-back is one of the most evidence-backed retention techniques, but manually reviewing 30 explain-it-back recordings per assignment is impractical without AI assistance. This makes a research-proven technique feasible at classroom scale.

## 3. City Builder AI Stakeholder Sim
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Quantum Tycoon (University of Barcelona, 2026) and the trend toward strategy simulations that embed domain concepts into game mechanics

### Description
Students build a simplified browser-based city simulation where AI-powered stakeholder agents (residents, business owners, environmental advocates, city council members) react to the player's zoning and budget decisions with realistic, contextual LLM-generated responses. The assignment teaches multi-agent integration, game loop design, and civic systems thinking in a single project that's genuinely fun to play and build.

### Key Features
- Tile-based city grid with zoning types (residential, commercial, industrial, green space)
- Four distinct AI stakeholder personas with persistent memory across turns (Claude API)
- Budget and approval-rating system that responds to agent sentiment
- Agent reasoning trace panel so players see why each stakeholder reacted as they did
- Week-by-week simulation turns with a news-ticker summarizing agent reactions

### Suggested Tech Stack
React, Vite, Tailwind, Supabase (game state persistence), Claude API (stakeholder agents with system prompts per persona), Phaser.js or plain Canvas for the tile grid

### Why It's Interesting
Combining game development with live AI agent integration gives students a meaningful capstone that spans front-end, backend, and AI API skills, while the civic scenario naturally raises AI ethics questions about whose voices the system amplifies.
