# Project Ideas for 2026-06-06

## 1. Persona Review Panel
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Hacker News discussions on AI code review tools and multi-persona AI experiments (https://news.ycombinator.com/item?id=46345827)

### Description
A web app where you paste or link a GitHub PR and watch multiple AI reviewer personas (grumpy senior engineer, security auditor, accessibility specialist, junior dev, product manager) simultaneously stream their critiques in side-by-side panels. Each persona has a distinct voice and focus area, making code review both educational and entertaining. Results can be exported as a structured report.

### Key Features
- Paste code or provide a GitHub URL to get instant multi-persona review
- Each persona streams its review in real time in its own panel with a distinct style
- "Ask a persona" follow-up chat to drill into specific concerns
- Export the full panel as a shareable Markdown or HTML report

### Suggested Tech Stack
React + Vite + Tailwind for the frontend, Claude API with streaming for the personas, optional Flask backend for GitHub URL fetching

### Why It's Interesting
It reframes code review as a performance that is genuinely fun to watch, and exposes developers to concerns they might not think to ask about on their own.

## 2. Demo Rescue Kit
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** The universal CS-professor experience of live coding demos breaking at the worst moment

### Description
A Flask/React tool where a professor pastes their live-demo plan (outline, code snippets, learning goals) before class and the AI generates a set of "rescue snapshots": working versions of the code at each stage that can be copy-pasted instantly if something breaks. It also generates a "what went wrong and why" card for the most likely failure points, turning bugs into teachable moments rather than awkward silences.

### Key Features
- Parse a demo outline and auto-generate versioned rescue snapshots for each stage
- Flag high-risk steps (e.g., live API calls, environment-dependent commands) and suggest safer fallbacks
- One-click copy of any snapshot to clipboard, or export as a runnable ZIP
- Optional "explain the bug" mode that generates a student-facing explanation card for common errors

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask backend, Claude API for plan analysis and snapshot generation, local file download (no database needed for MVP)

### Why It's Interesting
It solves a real, specific pain point that every CS instructor has felt, and the fallback explanations actually turn demo disasters into curriculum opportunities.

## 3. Replication Lab
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Growing emphasis on ML reproducibility and GitHub trending open-source AI repos (https://ossinsight.io/trending/ai)

### Description
A platform where students are assigned published ML or CS research papers and must replicate the key results from scratch, documenting every decision in a structured lab notebook. An AI assistant helps them parse the paper, suggests implementation strategies, and tracks exactly how much help was given, producing an "independence score." Instructors get a dashboard showing replication accuracy, help usage, and common sticking points across the class.

### Key Features
- Paper ingestion: paste a DOI or PDF and the AI extracts the key claims, datasets, and metrics to replicate
- Guided lab notebook with prompted sections (hypothesis, implementation choices, results, discrepancy analysis)
- AI hint system that logs every hint given and feeds into a per-student independence score
- Instructor dashboard with class-wide heatmaps of where students struggled most

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask + Supabase backend (notebooks and scores), Claude API for paper parsing and hint generation, Gemini API as an alternative model students can compare

### Why It's Interesting
It builds deep research literacy and teaches scientific reproducibility, two skills that are increasingly critical as AI-generated code and papers flood the field, while giving instructors genuine insight into student understanding.
