# Project Ideas for 2026-06-02

## 1. Local Model Router
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub trending June 2026 — OpenClaw (personal AI gateway connecting to 50+ integrations) and Ollama's continued dominance in local inference; developer frustration with manually picking which local model to use per task

### Description
A small web dashboard that intelligently routes prompts to different locally-hosted Ollama models based on detected task type (reasoning, coding, summarization, creative writing). The user pastes a prompt, the router classifies it and dispatches it to the most appropriate model, then shows the response alongside latency, token count, and routing rationale.

### Key Features
- Automatic task-type classifier (uses a fast model or heuristics to detect coding vs. reasoning vs. creative)
- Live routing decision panel showing which model was chosen and why
- Side-by-side latency and token stats across recent requests
- Simple config file to register available Ollama models and their strengths

### Suggested Tech Stack
React + Vite + Tailwind for the dashboard, Flask for the routing backend, Ollama REST API for model inference

### Why It's Interesting
Local LLM setups keep growing but managing multiple specialized models manually is tedious; an automatic router makes the workflow feel seamless and teaches task-classification as a practical AI technique.

## 2. Difficulty Dial
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** MagicSchool AI's differentiated lesson plan generation (ranked among top classroom AI tools in 2026) and reports that 69% of teachers say AI tools improved their teaching but creation of tiered assignments remains manual

### Description
A React web app where a CS professor pastes any programming assignment prompt and turns a "difficulty dial" from Scaffolded to Standard to Advanced. Claude API rewrites the same core problem at each tier: the scaffolded version adds starter code, guided hints, and broken-down steps; the standard version is clean; the advanced version strips scaffolding and adds extension constraints or open-ended design questions.

### Key Features
- Three-tier output (Scaffolded / Standard / Advanced) generated in one click
- Editable output so professors can tweak before exporting
- Grading criteria auto-adapted to match each tier's expectations
- Export to Markdown or PDF for direct pasting into an LMS

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask backend, Claude API for generation

### Why It's Interesting
Differentiated assignments are a known best practice for mixed-skill CS classrooms but manually writing three versions of every problem is prohibitive; this makes tiering fast enough to actually happen.

## 3. Model Card Studio
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Growing AI transparency requirements in 2026 (AI ethics education trends, regulatory pressure for model documentation) and a gap in tooling that makes writing model cards approachable for students

### Description
Students build an interactive guided web app that walks a user through creating a structured model card for any AI system — covering training data sources, intended use cases, known limitations, fairness metrics, and ethical risks. An AI assistant (Claude or Gemini) asks clarifying questions, suggests content for each section based on the model type described, and flags missing disclosures. The final output exports as a shareable Markdown or PDF model card.

### Key Features
- Section-by-section wizard with AI-generated suggestions for each field
- Red-flag detection: warns if the user skips bias evaluation or out-of-scope use cases
- Template library of real model cards (GPT, BERT, Stable Diffusion) for reference
- Supabase storage so users can save, version, and share their cards

### Suggested Tech Stack
React + Vite + Tailwind, Supabase for auth and card storage, Claude API or Gemini API for section suggestions

### Why It's Interesting
Writing model cards is becoming a professional and regulatory requirement for AI practitioners, yet few students graduate knowing how; building the tool forces students to internalize every component of responsible AI documentation.
