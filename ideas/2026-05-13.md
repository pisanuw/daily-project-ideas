# Project Ideas for 2026-05-13

## 1. Debate My Code
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** HN "Ask HN: What are you working on? (May 2026)" thread (https://news.ycombinator.com/item?id=48085993) and r/SideProject trend of AI-powered developer tools that make code review more engaging

### Description
A web app where a developer pastes a code snippet and an AI plays devil's advocate, presenting both a defense and a critique of the design decisions, naming specific tradeoffs. It turns the usually-solitary act of self-review into a structured back-and-forth debate, making it easier to spot blind spots before a pull request.

### Key Features
- Paste any code snippet and choose a focus (readability, performance, security, or maintainability)
- AI generates a structured "for vs. against" debate with concrete arguments on each side
- Follow-up round where the user rebuts one argument and the AI responds, deepening the analysis
- Shareable debate permalink so teams can discuss asynchronously

### Suggested Tech Stack
React + Vite + Tailwind for the frontend, Claude API (claude-sonnet-4-6) for structured debate generation, Supabase for storing and sharing debate sessions

### Why It's Interesting
It reframes AI-assisted code review as an active thinking exercise rather than passive suggestion-reading, which makes it both more engaging and more educational for developers at any level.

## 2. Live Classroom Pulse
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** DeepTutor agent-native personalized learning assistant (https://aitoolly.com/ai-news/article/2026-04-09-deeptutor-an-agent-native-personalized-learning-assistant-developed-by-hkuds-research-team) and GitHub's continuous AI for accessibility/feedback triage workflow (https://github.blog/ai-and-ml/github-copilot/continuous-ai-for-accessibility-how-github-transforms-feedback-into-inclusion/)

### Description
A real-time web app for live lectures where students anonymously post short confusion signals or questions via their phones, and an AI clusters and ranks the top confusions on the professor's dashboard within seconds. After class, it generates a structured debrief report showing which concepts need more coverage next session.

### Key Features
- Students join a session via a short code, no account required, and submit anonymous "stuck" messages in real time
- AI clusters similar questions and displays a live ranked list on the instructor's view, updated every 30 seconds
- Instructor can mark a cluster as "addressed" and it drops from the live board
- Post-session PDF report with top confusions, question volume over time, and suggested follow-up topics

### Suggested Tech Stack
React + Vite + Tailwind frontend, Supabase Realtime for live updates, Flask backend, Claude API for clustering and summarization, Supabase Postgres for session storage

### Why It's Interesting
It solves the "silent confusion" problem in large CS lectures without requiring students to interrupt, and the AI clustering means a professor with 80 students gets actionable signal rather than noise.

## 3. Agent Arena
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Top trending multi-agent AI frameworks on GitHub in 2026 including CrewAI and MetaGPT (https://fungies.io/top-github-repositories-ai-agent-frameworks-2026/) and the broader trend of open-source AI agent toolkits surging in popularity

### Description
Students implement competing AI agents that play a simple turn-based resource-collection game on a shared server. Each agent calls an LLM API (Claude or Gemini) to decide moves based on visible game state, and a tournament bracket system runs elimination rounds. The assignment teaches prompt engineering, agent state design, and emergent multi-agent behavior through direct competition.

### Key Features
- A browser-based game board visualizer showing all agents playing live, built with React
- A defined REST API students implement their agent against, callable in any language
- Tournament scheduler that runs round-robin then single-elimination brackets automatically
- Agent "autopsy" view after each match showing the prompts used and move history, so students can learn from opponents

### Suggested Tech Stack
React + Vite + Tailwind for the spectator/bracket UI, Flask for the game server and tournament scheduler, Supabase for match history and leaderboards, Claude API or Gemini API for student agents (students bring their own key)

### Why It's Interesting
Competition creates intrinsic motivation for iterating on prompt engineering and agent design, and the shared leaderboard makes learning feel like a game rather than homework. It also naturally raises AI ethics questions about strategy and fairness that professors can facilitate.
