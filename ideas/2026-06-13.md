# Project Ideas for 2026-06-13

## 1. Context Window Cartographer
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub trending May 2026 showing token efficiency as the dominant theme; developers building LLM apps struggling to visualize where their context budget goes (https://ecoaai.com/top-10-trending-ai-repositories-on-github-end-of-may-2026-edition/)

### Description
A small interactive web app that takes a Claude or OpenAI conversation thread (pasted as JSON or via API key) and renders a stacked bar / timeline visualization showing exactly how the context window is consumed: system prompt, tool definitions, user messages, assistant responses, and tool call results. Token counts update live as you add messages, and colored zones show how close you are to the model's limit.

### Key Features
- Paste or import a conversation JSON and see an immediate token-by-token breakdown by message role
- Live "remaining context" gauge that turns yellow/red as the window fills
- Side-by-side comparison of two conversation designs to show which is more token-efficient
- Export a static summary image or shareable link

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (for tokenization via the token-counting endpoint), tiktoken (for OpenAI counts)

### Why It's Interesting
Token budgeting is now a core skill for LLM app developers, but most people guess rather than measure. This makes the invisible visible in under a weekend, and doubles as a teaching demo for any course that covers LLM application design.

## 2. Office Hours Replay Engine
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Recurring instructor pain point of running the same explanations each semester; trend of AI tools processing transcripts and extracting actionable insights (https://www.edcafe.ai/blog/best-ai-teaching-tools)

### Description
An instructor uploads transcripts or audio recordings from past office hours sessions. The app uses an LLM to extract recurring questions, cluster them by concept, score their frequency, and generate a "confusion heat map" report linking each cluster to the relevant course topic. The instructor gets a ranked list of concepts to address proactively in future lectures or FAQs.

### Key Features
- Upload plain-text transcripts or audio files (Whisper transcription built in)
- LLM-powered extraction and clustering of student questions by concept
- Visual heat map showing which topics generate the most confusion per week
- One-click generation of a draft FAQ document or pre-lecture slide insert

### Suggested Tech Stack
React, Vite, Tailwind (frontend), Flask (backend), Claude API (question extraction and clustering), Whisper API (audio), Supabase (storage and session history)

### Why It's Interesting
Instructors run office hours every semester but rarely mine that data systematically. This turns a passive record into actionable curriculum intelligence, directly improving future lectures without adding grading burden.

## 3. AI Ethics Court Simulator
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Growing demand for AI ethics curricula and the trend toward adversarial multi-agent simulations for teaching nuanced reasoning (https://dev.to/anmolbaranwal/open-source-toolkit-for-building-ai-agents-in-2026-55h1)

### Description
Students build a web app where multiple AI agents play roles in a simulated ethics tribunal: a defendant AI system (accused of a specific harm such as bias, privacy violation, or misinformation), a prosecuting attorney agent, a defense attorney agent, expert witness agents, and a judge agent that renders a reasoned verdict. Each agent is given a written "constitution" defining its position, values, and argumentative style. Students present a real-world AI ethics case, watch the agents argue it, and evaluate the verdict quality.

### Key Features
- Configurable role cards: students write each agent's constitution and initial position statement
- Turn-based argument loop with a moderator agent enforcing courtroom procedure
- Judge agent produces a structured verdict with cited reasoning from the arguments
- Post-trial reflection interface where students annotate agent failures and biases they observed

### Suggested Tech Stack
React, Vite, Tailwind (frontend), Flask (backend), Claude API (multi-agent orchestration), Supabase (case records and student annotations)

### Why It's Interesting
It forces students to operationalize abstract ethics concepts as concrete agent instructions, exposes how framing shapes AI outputs, and produces artifacts (verdicts, annotations) that make for rich class discussion and graded reflection.
