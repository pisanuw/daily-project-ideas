# Project Ideas for 2026-05-20

## 1. Agent Audit Trail
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** https://news.ycombinator.com/item?id=48063548 (Show HN: Git for AI Agents) and https://github.com/regent-vcs/re_gent

### Description
A lightweight React + Supabase dashboard that captures every step an AI agent takes during a run (tool calls, model decisions, outputs) and stores them as a structured timeline. You can replay any past run step-by-step, diff two runs side-by-side, and annotate steps with notes explaining why something went wrong. Think "DVR for AI agents" — built for developers debugging agentic pipelines.

### Key Features
- Auto-logging SDK shim that wraps Claude/Gemini API calls and writes each turn to Supabase
- Timeline replay UI showing tool inputs, outputs, and token counts per step
- Side-by-side run diff to compare a broken run against a working one
- Shareable run permalink for async debugging with teammates

### Suggested Tech Stack
React, Vite, Tailwind, Supabase (Postgres + Realtime), Claude API, Python or Node shim library

### Why It's Interesting
AI agent debugging is one of the biggest unsolved pain points in 2026, and almost no lightweight self-hosted tooling exists for it. A weekend-scale version would immediately be useful to any developer running agentic workflows.

## 2. Peer Review Simulator
**Category:** Teaching Tool
**Complexity:** Multi-week
**Inspired by:** Trends in AI education tools (May 2026 HN "What are you working on?" thread and AI teacher tool roundups)

### Description
Students submit code, an essay, or a design doc, and the tool responds with feedback from three distinct AI personas: a harsh technical critic, a supportive peer, and a domain-expert outsider. Each persona uses a different rubric and tone so students see how the same work lands differently depending on the reader. A final "synthesis" view extracts the common threads across all three reviews.

### Key Features
- Three configurable reviewer personas (instructor defines personality, expertise, and rubric)
- Side-by-side comparison of all three reviews with color-coded agreement/disagreement
- Synthesis panel that highlights points all reviewers flagged (likely real issues)
- Instructor dashboard showing which students received consistently harsh vs. consistently positive reviews, flagging outliers for human follow-up

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase, Claude API (separate system prompts per persona), Claude prompt caching for shared rubric context

### Why It's Interesting
Teaching students to write for multiple audiences is a core CS communication skill, and seeing the same work through three distinct lenses makes the abstract concrete. Prompt caching makes running three separate LLM calls per submission cost-effective at classroom scale.

## 3. Live Interview Coach
**Category:** Classroom Assignment
**Complexity:** 1-2 Weeks
**Inspired by:** https://blog.bytebytego.com/p/top-ai-github-repositories-in-2026 (AI skills frameworks trending on GitHub, mattpocock/skills) and https://news.ycombinator.com/item?id=48085993 (Ask HN: What are you working on? May 2026)

### Description
A web app that simulates a real technical coding interview: the AI interviewer presents a LeetCode-style problem, listens to the student's typed explanation before they code, asks probing follow-up questions ("What's your time complexity?", "Can you handle edge case X?"), and gives a timestamped post-session debrief with a rubric score and specific improvement tips. The student experiences the pressure of a live interview without needing a human partner.

### Key Features
- Configurable difficulty and problem category (arrays, graphs, dynamic programming, system design)
- Real-time "thinking out loud" phase before coding, where the AI asks clarifying questions
- AI evaluates code correctness, explanation clarity, and edge-case handling independently
- Post-session PDF report with timestamped transcript, rubric scores, and two targeted practice recommendations

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (streaming for real-time interviewer responses), Flask backend, Supabase for session history, Monaco Editor for in-browser coding

### Why It's Interesting
Coding interview prep tools exist but almost none simulate the conversational pressure of a real interview; most just run test cases silently. The multi-turn dialogue with probing follow-ups is what makes this genuinely practice for the real thing.
