# Project Ideas for 2026-05-24

## 1. Review Vibe Meter
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** OpenClaw's multi-agent audit capabilities and growing awareness of toxic code review culture in open source communities

### Description
A web tool that analyzes the emotional tone and constructiveness of GitHub pull request comments and code reviews. It assigns a "vibe score" to individual reviewers and entire PRs, flagging patterns of discouragement, frustration, or toxicity while celebrating positive review cultures. Teams can paste PR URLs or raw comment threads and get an instant cultural health report.

### Key Features
- AI-scored tone analysis per comment (constructive, neutral, dismissive, toxic)
- Reviewer "vibe profile" showing historical patterns across a repo
- Team-level culture dashboard with trend lines over time
- Actionable rewrite suggestions for low-scoring comments

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (for tone analysis), GitHub REST API (to fetch PR comments), Supabase (for storing scores and history)

### Why It's Interesting
Code review culture directly affects contributor retention and team morale, but almost no tooling exists to measure it. This fills a real gap and is immediately demonstrable on any public repo.

## 2. Multi-Agent Ethics Roundtable
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** OpenClaw's multi-agent architecture, game-based learning trends in 2026, and the need for structured CS ethics discussion in classrooms

### Description
A classroom web app where an instructor poses a real CS ethics dilemma (facial recognition in hiring, data retention policies, algorithmic content moderation) and multiple AI agents each embody a distinct ethical framework (utilitarian, deontological, virtue ethics, critical theory, techno-optimist) and debate in real time. Students moderate the debate by submitting follow-up questions and must ultimately argue for a position and justify it.

### Key Features
- Instructor dashboard to configure dilemmas and select which ethical frameworks to activate
- Live debate view showing each agent's evolving position as the argument unfolds
- Student "intervention" mode to ask any agent a direct question mid-debate
- Post-debate reflection prompt generator and exportable transcript for grading

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (multi-turn with distinct system prompts per agent), Supabase (sessions and transcripts), Flask (backend orchestration)

### Why It's Interesting
Ethics instruction often feels abstract; watching AI agents argue from distinct philosophical positions gives students a concrete, engaging entry point and forces them to evaluate competing moral reasoning rather than passively consume a lecture.

## 3. Agent Skills Workshop
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** OpenClaw's skills directory system (SKILL.md files), the GitHub trend of "Karpathy AI engineering skills packaged for agents," and the agent frameworks dominating GitHub trending in 2026

### Description
Students design and publish AI agent skill packs targeting a specific CS education subdomain (e.g., "Python debugging tutor," "web accessibility checker," "big-O complexity explainer"). Each skill pack follows a SKILL.md + tools convention, and a shared class marketplace lets students install each other's skills into a local AI agent and evaluate them. The final deliverable is a published, documented skill pack alongside a peer evaluation report.

### Key Features
- Scaffold template repo with SKILL.md spec, example tools, and a test harness
- Class marketplace frontend where students browse, install, and rate each other's skill packs
- Automated smoke-test runner that checks if a skill produces coherent output on a set of benchmark prompts
- Reflection journal prompts built into the rubric covering agent design decisions and prompt engineering trade-offs

### Suggested Tech Stack
Python or Node.js (skill pack runtime), React + Supabase (marketplace and submissions), OpenClaw-compatible SKILL.md format, Claude API or Gemini API (agent backbone), GitHub for version-controlled skill submissions

### Why It's Interesting
Students learn agent architecture, prompt engineering, documentation, and peer evaluation in a single project, mirroring the open-source contribution workflow they will encounter professionally while producing artifacts that are actually useful to other students.
