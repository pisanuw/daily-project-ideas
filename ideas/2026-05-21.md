# Project Ideas for 2026-05-21

## 1. README Roast
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** HN thread on facts-driven documentation and "Show HN: TikTok but for scientific papers" (https://news.ycombinator.com/item?id=48096842) sparking interest in making technical content more engaging and shareable

### Description
A web app where you paste a GitHub repo URL or raw README text and the AI delivers a comedic "roast" of your documentation, pointing out missing sections, vague descriptions, stale badges, and broken links, then immediately provides a polished rewrite. The roast framing makes the feedback memorable and shareable as a card on social media, encouraging developers to actually fix their docs.

### Key Features
- Paste a GitHub URL or raw README markdown for instant analysis
- AI generates a comedic roast highlighting specific weaknesses (missing install steps, no license, walls of jargon)
- Side-by-side diff showing original vs. AI-rewritten README
- Shareable "roast card" image summarizing the score and funniest critique

### Suggested Tech Stack
React + Vite + Tailwind for the UI, Claude API for roast generation and rewrite, GitHub REST API for fetching README content, html-to-image for generating shareable cards

### Why It's Interesting
It turns a chore (improving documentation) into something fun and viral, and every developer with a side project is a potential user. It also demonstrates practical Claude API usage with constrained, persona-driven prompting.

## 2. Curriculum Graph Builder
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Trending visual workflow tools (n8n, Dify crossing 180k stars on GitHub trending) and AI teaching assistant tools like Curipod for structured lesson design (https://www.buildmvpfast.com/blog/best-open-source-ai-projects-github-2026)

### Description
A drag-and-drop visual tool for CS instructors to map course content as a knowledge graph, where nodes represent topics (recursion, sorting, memory management) and directed edges represent prerequisite relationships. The AI analyzes the graph to flag orphaned nodes, circular dependencies, and missing prerequisite links, and can auto-generate a quiz question for any selected node on demand.

### Key Features
- Interactive graph canvas (React Flow) for adding topics and drawing prereq edges
- AI audit that detects missing prerequisites and suggests connections based on topic names
- Per-node quiz generator that produces 3 multiple-choice questions in Bloom's Taxonomy format
- Export to a shareable JSON syllabus or printable visual map
- Student view where learners self-mark known nodes and see their knowledge gap highlighted

### Suggested Tech Stack
React + Vite + Tailwind, React Flow for graph canvas, Claude API for gap analysis and quiz generation, Supabase for persisting graph data, jsPDF or similar for export

### Why It's Interesting
CS professors design courses iteratively but rarely have tooling that makes prerequisite structure explicit and auditable. This fills a real gap in course design workflows and doubles as a student self-assessment tool.

## 3. NPC Constitution
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Hermes Agent autonomous framework reaching 105k GitHub stars and GitHub's AI accessibility constitutional approach (https://github.blog/ai-and-ml/github-copilot/continuous-ai-for-accessibility-how-github-transforms-feedback-into-inclusion/), combined with growing AI ethics curriculum needs

### Description
Students build a text-based adventure game where every NPC is powered by an LLM but must strictly follow a "constitution" the student writes: a set of plain-language rules specifying what the character can say, remember, refuse, or lie about. A rule-checking middleware layer intercepts LLM responses and flags or rejects violations, forcing students to think concretely about AI alignment, prompt injection, and the limits of rule-based constraints.

### Key Features
- Browser-based text adventure engine with at least 3 NPC characters
- Student-authored constitution editor where rules are written in natural language
- Middleware that evaluates each LLM response against the active constitution and logs violations
- "Jailbreak challenge" mode where classmates try to get NPCs to break their rules
- Reflection report generated by AI summarizing which rules held, which failed, and why

### Suggested Tech Stack
React + Vite for game UI, Flask or FastAPI backend for NPC orchestration and rule checking, Claude API for NPC dialogue generation, Supabase for game state and violation logs, Python for the constitution enforcement layer

### Why It's Interesting
It makes AI alignment tangible and hands-on: students experience firsthand that writing good rules is hard, that edge cases matter, and that rule conflicts are a fundamental alignment challenge, all while building something genuinely playable.
