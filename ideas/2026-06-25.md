# Project Ideas for 2026-06-25

## 1. TypeScript Type Puzzle Arena
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** GitHub Octoverse 2026 report showing TypeScript surpassing Python and JavaScript to become the #1 language on GitHub (https://github.blog/news-insights/octoverse/octoverse-a-new-developer-joins-github-every-second-as-ai-leads-typescript-to-1/)

### Description
A browser-based daily puzzle game where players solve TypeScript type-system challenges of increasing difficulty. Each puzzle presents broken or incomplete type definitions and the player must write the correct types to make the code compile. Think Wordle but for TypeScript types, with streak tracking and shareable results.

### Key Features
- Daily challenge with a fresh type puzzle seeded from a curated set
- In-browser TypeScript compiler feedback (red squiggles, error messages) so players see results instantly
- Difficulty tiers: Beginner (simple generics), Intermediate (conditional types), Expert (mapped types + infer)
- Share-your-score card showing solve time and number of attempts

### Suggested Tech Stack
Vite + React + TypeScript, Monaco Editor (for in-browser TS editing with compiler), Supabase for daily puzzle seeding and leaderboard, Tailwind for styling

### Why It's Interesting
TypeScript is now the dominant language on GitHub and yet most CS curricula skip the type system almost entirely. A daily puzzle game gives students a low-stakes way to build intuition for types and positions the creator as a go-to resource for the TS community.

## 2. Agent Reliability Harness
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Show HN: Statewright – Visual state machines that make AI agents reliable (https://news.ycombinator.com/item?id=48108778), which surfaced how hard it is to know whether an agent handles edge cases gracefully

### Description
A grading and evaluation harness that instructors deploy to test student-built Claude API agents against a battery of adversarial scenarios. It submits inputs such as ambiguous prompts, malformed tool responses, missing context, and contradictory constraints, then scores each submission on reliability, graceful error handling, and output quality. An instructor dashboard shows per-student pass/fail breakdowns so weak spots in agent design are immediately visible.

### Key Features
- Configurable scenario library: ambiguous inputs, tool timeouts, schema violations, adversarial jailbreak attempts
- Per-submission reliability score with a breakdown by scenario category
- Instructor dashboard with class-wide heatmap of which scenarios most students fail
- Student-facing report showing exactly which test cases their agent failed and why

### Suggested Tech Stack
Flask backend to run scenario orchestration, Claude API for test execution, React + Tailwind frontend for dashboards, Supabase for storing submissions and scores, Docker for isolated agent sandboxing

### Why It's Interesting
As more CS courses assign AI agent projects, instructors have no good tools to objectively compare implementations. This fills that gap directly, making it easy to see which students understand agent robustness and which are just happy-path testing.

## 3. Multi-Source Research Synthesizer
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Trending multi-agent frameworks on GitHub 2026 (CrewAI, MetaGPT, AutoGen all surging) and cloud parallel coding agents like Broccoli (https://news.ycombinator.com/item?id=47865642) showing the value of decomposing tasks across parallel agents

### Description
Students build a multi-agent pipeline that takes a research question, autonomously searches ArXiv, Wikipedia, and news APIs, assigns specialized agents to each source, extracts key claims, cross-references them for contradictions, and produces a structured literature review with inline citations. The assignment teaches agent orchestration, retrieval-augmented generation, and parallel task decomposition in a concrete, verifiable context.

### Key Features
- Source-specific agents that each know how to parse and extract claims from their assigned source type
- Contradiction detector agent that compares claims across sources and flags conflicts with evidence
- Synthesis agent that writes a structured review document from the verified claims
- Evaluation rubric: citation accuracy, contradiction identification rate, coherence of final output

### Suggested Tech Stack
Python with Claude API (multi-agent orchestration), ArXiv API + Wikipedia API + NewsAPI for retrieval, Supabase to cache fetched documents, React frontend for displaying the structured review and source provenance

### Why It's Interesting
It forces students to think about task decomposition, inter-agent communication, and trust between agents, which are exactly the hard problems in production AI systems. The research output is also independently verifiable, making grading objective rather than subjective.
