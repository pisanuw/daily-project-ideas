# Project Ideas for 2026-06-04

## 1. Error Autopsy
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Research finding that 84% of developers use AI tools but see only 10-30% productivity gains, especially for debugging (https://www.secondtalent.com/resources/ai-developer-productivity-tools-2026/ and https://stackoverflow.blog/2026/03/05/developerweek-2026/)

### Description
A focused web app where you paste an error message or stack trace alongside a short description of what you were trying to do. Claude performs a forensic analysis: identifying the root cause, ranking likely contributing factors, and providing a step-by-step fix tailored to your exact error rather than generic advice. Unlike asking an LLM directly, the UI enforces the context needed to give a good answer.

### Key Features
- Structured input form (error text, language/framework, what you were attempting)
- AI-generated root cause breakdown ranked by likelihood
- Step-by-step fix with code snippets
- "Related errors" suggestions for common follow-on issues
- Optional screenshot paste using Claude vision for GUI or browser errors

### Suggested Tech Stack
React + Vite + Tailwind, Flask backend, Claude API (with vision support), no auth needed for MVP

### Why It's Interesting
Debugging is where AI tools consistently underperform, yet it consumes enormous developer time. A tightly scoped tool that forces good context collection and returns structured forensic output is more useful than a generic chatbot for this specific workflow.

## 2. Study Buddy Matchmaker
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Ask HN "What are you working on?" threads and education research on complementary peer learning (https://news.ycombinator.com/item?id=48085993)

### Description
A classroom tool that analyzes anonymized student quiz and assignment performance to identify complementary knowledge gap profiles, then suggests optimal study group pairings. Student A is strong in recursion but shaky on graphs; student B is the reverse. The system matches them and generates a shared study agenda with resources targeting each person's gaps.

### Key Features
- Instructor dashboard to upload or connect quiz/assignment score data
- Claude-powered analysis that clusters students by strength/weakness profiles
- Printable or shareable study group cards showing each pair's focus topics
- Auto-generated study agenda with curated resources for each gap area
- Privacy-first: students only see their own gaps, not peers' data

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask + Supabase backend, Claude API for profile clustering and agenda generation

### Why It's Interesting
Peer learning research consistently shows that students learn better from someone who recently mastered a concept than from an expert, yet most study group formation is random. Automating complementary matching makes an evidence-backed pedagogy trivially easy to deploy.

## 3. Real-Time Accessibility Overlay
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** GitHub's continuous AI for accessibility initiative and 2026 AI accessibility tooling trends (https://github.blog/ai-and-ml/github-copilot/continuous-ai-for-accessibility-how-github-transforms-feedback-into-inclusion/)

### Description
Students build a browser extension that injects AI-generated accessibility improvements onto any live webpage in real time: synthesizing missing alt text from image content, adding ARIA labels to unlabeled controls, and overlaying a keyboard-navigation highlight ring. The extension calls a Claude vision endpoint to analyze visible page regions on demand and streams improvements back into the DOM without page reload.

### Key Features
- One-click activation that scans the current page and highlights accessibility issues
- AI-generated alt text injected directly onto images with no original alt attribute
- ARIA label suggestions overlaid on form controls and icon buttons
- Keyboard navigation mode that shows a visible focus ring and skip-link overlay
- Export report of all injected fixes as an annotated HTML diff

### Suggested Tech Stack
Chrome/Firefox Manifest V3 extension, content scripts + background service worker, Claude API (vision) or Gemini API, React-based options/popup page, Tailwind for injected overlay styles

### Why It's Interesting
This assignment teaches browser extension architecture, vision AI integration, DOM manipulation, and WCAG principles all in one project, and the deliverable is immediately usable on any real website, giving students tangible proof that their work improves the web.
