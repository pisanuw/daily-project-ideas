# Project Ideas for 2026-06-14

## 1. Code Time Capsule
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** "Ask HN: What developer tool do you wish existed in 2026?" (https://news.ycombinator.com/item?id=46345827) and the broader trend of reflecting on past architectural decisions

### Description
A web app where you write a short snippet of code and a note explaining your design choices, then set a future date for delivery. On that date, an AI reviews the snippet and your rationale against current best practices, emerging patterns, and known pitfalls that have been documented since you wrote it, then sends you an email with a candid "did your choices age well?" report.

### Key Features
- Code + rationale entry form with a date picker for the "open on" date
- Supabase-backed scheduled jobs to trigger the AI review on the chosen date
- Claude API review comparing original reasoning to up-to-date practices
- Email delivery of the AI report with inline code annotations

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase (storage + cron triggers), Claude API, SendGrid or Resend

### Why It's Interesting
It turns hindsight into a learning loop, making it useful for personal reflection and as a classroom demonstration that good engineering involves revisiting old decisions, not just making new ones.

## 2. Visual Rubric Grader
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Show HN: ProofShot - Give AI coding agents eyes to verify the UI they build (https://news.ycombinator.com/item?id=47499672)

### Description
Professors define rubrics for UI or design assignments using checkboxes and natural-language criteria (e.g., "navbar is visible on mobile", "primary button uses accessible contrast"), then students submit screenshots. Claude Vision evaluates each screenshot against the rubric and produces a scored, annotated feedback report without any manual review per submission.

### Key Features
- Rubric builder interface where instructors define visual criteria with point weights
- Student submission portal that accepts image uploads
- Claude Vision API evaluation that maps each rubric item to a pass/fail with a brief explanation
- Instructor dashboard showing class-wide score distributions and flagged edge cases for human review

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase, Claude API (vision), PDF or HTML report export

### Why It's Interesting
It solves a real pain point: UI assignments are graded slowly because visual inspection is tedious, and this approach makes AI-assisted grading concrete and auditable rather than black-box.

## 3. Code Forensics Studio
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Agentic AI Summit 2026 (https://rdi.berkeley.edu/events/agentic-ai-summit-2026) and DeerFlow 2.0 multi-agent framework trends

### Description
Students are handed an unfamiliar open-source codebase and orchestrate a team of specialized AI agents (a dependency mapper, a security auditor, a code-style historian, and a documentation writer) to collaboratively reverse-engineer its architecture and produce a structured analysis report. The final deliverable is both the generated report and a written critique of where the agents agreed, disagreed, or missed the mark.

### Key Features
- Agent orchestration layer where students configure agent roles and communication order
- Each agent focuses on a narrow lens: dependencies, security vulnerabilities, style evolution, missing docs
- Agents exchange findings and can query each other for clarification before producing a final merged report
- Student reflection template asking them to evaluate agent accuracy against their own code reading

### Suggested Tech Stack
Claude API (multi-turn, tool use), React frontend for the agent dashboard, Flask backend, Supabase for storing agent runs and outputs

### Why It's Interesting
It combines multi-agent system design with software engineering fundamentals, giving students a hands-on reason to understand both LLM coordination patterns and legacy code comprehension at the same time.
