# Project Ideas for 2026-06-30

## 1. Presentation Pacer
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** HN discussion on developer productivity tools (https://news.ycombinator.com/item?id=46345827) and the growing trend of AI coaching tools for async skill-building

### Description
A browser-based presentation practice tool where you paste your slide content or upload a deck, then advance slides with the space bar while speaking. On finish, the Claude API analyzes your per-slide timing and an optional Web Speech API transcript to give coaching: which slides you rushed, where your explanation was unclear, and concrete pacing suggestions. Everything runs client-side with no backend required.

### Key Features
- Paste or upload slide content; advance slides with keyboard
- Per-slide timer tracking with visual heatmap of fast vs. slow slides
- Optional live speech transcription via Web Speech API
- Claude API post-session coaching report with specific, actionable feedback
- Export coaching report as markdown or PDF

### Suggested Tech Stack
React + Vite + Tailwind, Web Speech API, Claude API (client-side via SDK), optional PDF export with jsPDF

### Why It's Interesting
Public speaking is a genuine pain point for students and developers alike, yet most practice tools are either expensive or require video recording and manual review. This makes AI coaching frictionless and immediate.

## 2. AI Research Methods Lab
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Karpathy's autoresearch project (https://github.com/karpathy/autoresearch), which showed the value of having AI agents run systematic ML experiments autonomously overnight

### Description
A classroom tool where students design and run small-scale AI behavior experiments. A student writes a hypothesis ("does adding two examples improve Claude's Python code quality?"), defines test cases and a scoring rubric, and the tool automatically runs the experiment across multiple Claude API calls, logs results in a structured table, and walks the student through writing a mini research report with methods, results, and discussion sections. The goal is to teach scientific method alongside AI evaluation literacy.

### Key Features
- Hypothesis and variable definition form with guided prompts
- Automated experiment runner that sends batched API calls and logs structured results
- Side-by-side response diff viewer for comparing conditions
- AI-assisted write-up scaffold (methods, results, discussion templates)
- Class dashboard for instructors to see all student experiments and share interesting findings

### Suggested Tech Stack
React + Vite + Tailwind (frontend), Flask + Supabase (backend and result storage), Claude API for experiment execution and write-up coaching

### Why It's Interesting
Most AI literacy curricula focus on using AI tools, not on evaluating them rigorously. This gives students a taste of real empirical AI research methodology without requiring ML expertise or GPU access.

## 3. Synthetic Learner Studio
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Inworld AI's NPC character work (https://www.analyticsinsight.net/artificial-intelligence/top-10-ai-game-development-tools-in-2026-you-should-know) applied to pedagogy, and AI-in-education trends around understanding diverse learning styles

### Description
Students build a multi-agent system in which each AI agent plays a "synthetic student" with a distinct, persistent learning profile: a visual learner who asks for diagrams, an anxious test-taker who second-guesses everything, a fast grasper who skips steps, and a misconception-holder with a known wrong mental model. The real student feeds these synthetic learners a lesson explanation and observes how each responds differently, then iterates their teaching until all profiles are satisfied. The exercise builds empathy for diverse learners while teaching practical AI agent design.

### Key Features
- Configurable synthetic student profiles with persistent memory across a conversation session
- Side-by-side chat UI showing all learner agents responding in parallel
- "Satisfaction meter" per profile that updates as the lesson improves
- Profile editor so instructors can add domain-specific misconceptions for a course
- Session export showing which explanations resonated with which profiles and why

### Suggested Tech Stack
React + Vite + Tailwind (frontend), Flask + Supabase (session storage and profile management), Claude API for each synthetic student agent with distinct system prompts and persistent context
