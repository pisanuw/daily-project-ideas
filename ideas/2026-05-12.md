# Project Ideas for 2026-05-12

## 1. Prompt Duel
**Category:** Teaching Tool
**Complexity:** Weekend
**Inspired by:** Show HN: Cerno (CAPTCHA targeting LLM reasoning, not human biology) + growing AI ethics curriculum needs in CS programs

### Description
A real-time multiplayer classroom game where students compete by crafting prompts to accomplish a shared goal (persuade, summarize, reframe a scenario) and an AI judge scores the outputs against a rubric. The game surfaces how small wording changes produce wildly different AI behavior, making prompt engineering and AI unpredictability viscerally concrete rather than abstract.

### Key Features
- Live lobby with room codes (students join on phones/laptops)
- Each round: shared goal + constraints (max 30 words, no imperative verbs, etc.)
- Claude API judges outputs on rubric dimensions and explains its scoring
- Leaderboard with per-round breakdowns showing why certain prompts won
- Professor mode: create custom rounds tied to specific ethics topics (bias, tone, factuality)

### Suggested Tech Stack
React + Vite + Tailwind for UI, Supabase Realtime for multiplayer sync, Claude API for judging and explanation, Flask backend for round orchestration

### Why It's Interesting
It turns a typical lecture on prompt engineering into a competitive game that generates genuine surprises — students discover edge cases and failure modes themselves rather than being told about them.

## 2. Code Blindfold
**Category:** CS Education Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Stony Brook CS papers at CHI 2026 on accessibility and human-AI interaction + discussions around AI-assisted grading tools that give actionable feedback

### Description
A web tool where students paste a URL to their deployed project and an AI agent crawls it, then generates a structured accessibility report simulating how the page is experienced across four disability profiles: low vision, color blindness, keyboard-only navigation, and screen reader use. Each issue links to the exact DOM element and includes a Claude-generated code fix.

### Key Features
- URL-based scanning with Playwright-driven page capture (screenshots + DOM snapshot)
- Four disability-profile simulations with visual overlays (e.g., deuteranopia filter applied to screenshot)
- Per-issue severity scores (WCAG level) with plain-language explanation of the real-world impact
- One-click "suggested fix" button calls Claude API to rewrite the offending HTML/CSS snippet
- Shareable report link for students to include in assignment submissions

### Suggested Tech Stack
React + Tailwind frontend, Flask API, Playwright for headless crawling, Claude API for issue explanation and fix generation, Supabase for storing reports

### Why It's Interesting
Most accessibility checkers output a wall of WCAG codes; this one shows students what their UI actually looks and feels like to a real user with that disability, making the feedback visceral and actionable rather than bureaucratic.

## 3. Ethical Lens
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Trending multi-agent orchestration systems (Gartner: 1,445% surge in multi-agent inquiries 2024–2025) + AI ethics as a required topic in CS curricula

### Description
A web app built as a classroom project where students construct a three-agent debate pipeline: a Proponent agent argues for a tech policy position, an Opponent agent argues against it, and a Moderator/Fact-Checker agent interrupts with cited corrections when either side makes a verifiable factual error. Students observe the debate live, score each round, and write a structured response comparing AI-generated arguments to their own reasoning.

### Key Features
- Topic library seeded with CS ethics scenarios (facial recognition in policing, AI hiring filters, data broker regulation, autonomous weapons)
- Three distinct Claude API agent personas with different system prompts and temperature settings
- Moderator agent triggers on factual claims and queries a grounding source before interjecting
- Debate transcript saved to Supabase with per-student annotation layer (highlight + comment)
- Professor dashboard: aggregate class sentiment scores per topic across all sessions

### Suggested Tech Stack
React + Vite + Tailwind, Flask backend for agent orchestration, Claude API (three concurrent calls with streaming), Supabase for transcripts and annotations, optional Gemini API grounding for fact-check queries

### Why It's Interesting
Building the system forces students to confront how agent persona, temperature, and system prompt design directly shape "opinion" — making AI ethics tangible through engineering rather than just reading about it.
