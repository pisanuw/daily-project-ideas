# Project Ideas for 2026-06-15

## 1. Agent Decision Tree Visualizer
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** https://github.com/trycua/cua (open-source computer-use agent infrastructure, trending on GitHub with 18k stars, June 2026)

### Description
Paste a raw AI agent session transcript (tool calls, reasoning steps, results) and this React app renders an interactive decision tree showing every branch point: what the agent considered, which tool it invoked, and what it chose next. Click any node to expand the full context or reasoning at that step. Export the tree as an SVG for slides or documentation.

### Key Features
- Parse pasted agent transcripts (JSON or plain text) into a structured tree via Claude API
- Interactive pan/zoom tree rendered with ReactFlow, collapsible nodes
- Node color-coding by tool type (search, code, file, web) and outcome (success, retry, fail)
- One-click SVG/PNG export for use in reports or teaching materials

### Suggested Tech Stack
React + Vite + Tailwind, ReactFlow for graph rendering, Claude API (Haiku for fast parse), local state only (no backend required)

### Why It's Interesting
As computer-use and multi-step agents become common, debugging "why did it do that?" is the hardest part. This tool makes agent reasoning legible in seconds, and doubles as a teaching artifact for AI courses.

## 2. TIL Board
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** HN "Ask HN: What are you working on? (June 2026)" community sharing pattern (https://news.ycombinator.com/item?id=48528779) and r/learnprogramming weekly learner posts

### Description
A lightweight classroom social board where students post one "Today I Learned" card per week: a concept they understood for the first time, a bug they finally fixed, or a tool they discovered. Claude automatically links each card to course topics, flags potential misconceptions for the professor, and surfaces the three most interesting TILs for opening class discussion.

### Key Features
- Students submit TIL cards (200 chars max + optional code snippet) via a simple React form
- Claude API auto-tags each card to course concepts and generates a 1-sentence "connection" note
- Professor dashboard showing weekly TIL feed, misconception alerts, and top picks
- Weekly email digest (via Supabase Edge Functions) with the class's best TILs

### Suggested Tech Stack
React + Vite + Tailwind, Supabase (auth, Postgres, Edge Functions), Claude API (Haiku for tagging), Resend for email

### Why It's Interesting
Structured weekly reflection is proven to deepen learning, but most professors never see what students actually "got" between lectures. This gives professors a passive signal about comprehension without grading burden.

## 3. Computer-Use Obstacle Course
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** https://github.com/trycua/cua (open-source computer-use agent sandboxes and benchmarks) and Cloudflare Agents Week 2026 (https://www.cloudflare.com/en-au/agents-week)

### Description
Students build a computer-use agent (using Claude's computer-use API) that can complete a specific browser-based task such as filling out a multi-step form, extracting a table from a PDF viewer, or comparing prices across three tabs. The real challenge: they also build an evaluation harness that runs their agent against 10 task variants and reports a completion rate. Grading is based on robustness (high completion rate across variants) rather than a single happy-path demo.

### Key Features
- Agent implementation using Claude computer-use API with a sandboxed Playwright browser
- Evaluation harness that generates 10 randomized variants of the target task (different field values, layouts, or sites)
- Completion-rate dashboard showing per-variant pass/fail with screenshots of failure points
- Writeup requirement: students document failure modes and what they changed to fix them

### Suggested Tech Stack
Python, Claude computer-use API (claude-sonnet-4-6), Playwright for sandboxed browser, Flask for the eval dashboard, Docker for reproducible sandboxing

### Why It's Interesting
Teaching agents through a single demo hides how brittle they are. Forcing students to hit 80%+ on 10 variants teaches them that reliability is the real engineering challenge, not just making the agent work once.
