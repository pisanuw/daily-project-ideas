# Project Ideas for 2026-06-24

## 1. Isometric CS Campus
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** isometric.nyc (trending on GitHub, June 2026) — a giant isometric pixel-art map of NYC; the idea adapts this for teaching CS concepts spatially

### Description
A playful browser toy that renders a university campus in isometric pixel art where every building houses a CS concept. Click the library to explore data structures with animated card stacks and queues, visit the robotics lab for a neural-net diagram, or head to the coffee shop for a live sorting-algorithm race. It's a visual, gamified entry point into a CS curriculum.

### Key Features
- Isometric canvas scene with 8-12 clickable campus buildings, each themed to a CS topic
- Per-building popup with a short animated explainer (GIF-style canvas animation)
- "Explore" mode that walks students through buildings in recommended curriculum order
- Shareable permalink per building so professors can link directly to a concept

### Suggested Tech Stack
Vite + TypeScript, HTML Canvas (or PixiJS for sprite management), Tailwind for UI panels, optionally Claude API for on-demand concept Q&A inside each building

### Why It's Interesting
Students remember spatial metaphors: "the sorting happens at the coffee shop" sticks better than slide 47 of a deck. It's also a fun weekend portfolio piece that doubles as a living CS reference site anyone can share or fork.

## 2. Live API Cost Meter
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Canvas IgniteAI Agent announcement (March 2026, Inside Higher Ed) and growing classroom use of Claude and Gemini APIs; HN discussions on AI budget transparency

### Description
A shared classroom dashboard that shows AI API costs accumulating in real time as students make calls during a lab session. A large "class budget" ticker ticks up on the projector while individual student rows show their token counts, latency, and cost per call. Students compete to write the most cost-efficient prompt that still passes a quality rubric, making cost-awareness a hands-on lesson rather than a slide topic.

### Key Features
- Real-time cost ticker per student and class aggregate, powered by Supabase Realtime
- Per-call breakdown: input tokens, output tokens, model tier, latency, USD cost
- "Efficiency leaderboard" ranking students by cost per quality point (rubric scored by Claude)
- Professor view: pause the class, replay a student's call history, compare two prompting strategies side-by-side

### Suggested Tech Stack
React + Vite, Tailwind, Supabase Realtime (cost events), Claude API + Gemini API (student calls proxied through a Flask middleware that logs usage), Python/Flask backend

### Why It's Interesting
Most students treat AI API calls as free until they see a real bill; watching the class budget burn on a projector in real time creates immediate intuition about token economy and prompt efficiency that no lecture achieves.

## 3. Execution Sound Map
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Accessibility-driven sonification research and the Wario Synth Show HN project (converts songs to Game Boy audio); applied here to make program execution audible rather than visual

### Description
A learning tool that turns Python or JavaScript execution traces into generative music: loops pulse at their iteration frequency, function calls ring distinct tones, recursion stacks harmonics on top of each other, and errors buzz a harsh chord. Students write code they can literally hear running, developing an auditory intuition for control flow and performance. The tool is also a genuine accessibility aid for visually impaired CS learners.

### Key Features
- Execution tracer that captures loop iterations, function calls, variable mutations, and exceptions
- Configurable sound palette: each construct type maps to a MIDI instrument and pitch range
- Side-by-side view: code on the left, a live piano-roll visualization on the right as it executes
- "Compose" mode: students write code with the goal of producing a specific musical phrase, reinforcing structured programming

### Suggested Tech Stack
Python (execution tracer via sys.settrace), Web Audio API or Tone.js (sound synthesis), React + Vite (piano-roll UI), WebSockets (streaming trace events from backend to browser), Flask

### Why It's Interesting
Sonification is an underexplored modality for CS education; hearing a nested loop build layered rhythms or a runaway recursion stack overflow into dissonance gives students a visceral, memorable signal that purely visual debuggers cannot replicate.
