# Project Ideas for 2026-06-05

## 1. Lecture Tape Deck
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Parrot (skeuomorphic audio recorder, Show HN May 2026) and the broader HN trend of delightful niche tools with personality

### Description
A retro-styled browser app that looks like a cassette player/tape deck, letting professors and students record lectures directly in the browser. Audio streams to a transcription API in real time, and the output is automatically formatted into clean, timestamped, section-structured lecture notes. Anyone with the link can follow along live.

### Key Features
- In-browser audio recording with a skeuomorphic cassette deck UI (play, pause, rewind controls)
- Real-time transcription with automatic section headings and bullet points via Claude Haiku
- Shareable read-only URL so students can access the live notes without installing anything
- One-click export to Markdown or PDF

### Suggested Tech Stack
React, Vite, Tailwind CSS, Web Audio API, Claude Haiku API (transcription + formatting), Supabase (note storage and real-time sync)

### Why It's Interesting
The retro UI makes it memorable and shareable, while the real utility (structured notes from audio) makes it genuinely useful in class. It is a tight enough scope to finish in a weekend but polished enough to put in a portfolio.

## 2. AI ROI Tracker
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** SecondTalent research (May 2026) showing 84% of developers use AI tools but see only 10% productivity gains on average

### Description
A classroom tool where students complete paired programming tasks: once with AI assistance enabled, once without (counterbalanced order to control for learning effects). The system automatically captures time-to-completion, test pass rate, and a self-reported confidence score, then generates a personal "AI ROI Report" at the end of the unit showing each student's actual vs. perceived productivity gains alongside anonymized class-wide data.

### Key Features
- Timed coding challenge runner with a built-in editor (Monaco) and test harness
- Session toggle that enables or disables AI autocomplete/suggestions for each attempt
- Per-student dashboard showing side-by-side comparisons: time, quality, confidence
- Class-wide aggregate view for the instructor, exportable as CSV for further analysis
- End-of-semester report generator with visualizations (bar charts, scatter plots)

### Suggested Tech Stack
React, Vite, Tailwind, Monaco Editor, Flask + Supabase (session storage and test execution sandbox), Claude API (code quality rubric scoring), Recharts (visualizations)

### Why It's Interesting
Forces students to think empirically about AI tools rather than accepting hype or dismissing them, and generates real data the instructor can use to improve the curriculum. It doubles as a research instrument that could produce publishable CS education findings.

## 3. API Archaeologist
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Kampala (YC W26, Launch HN June 2026) which reverse-engineers legacy web dashboards into clean APIs

### Description
Students build a browser extension plus a lightweight backend that acts as a recording proxy: it captures all HTTP requests and responses made by a target web app (a university portal, Canvas, a legacy SIS), deduplicates and clusters them by endpoint pattern, and then generates a full OpenAPI 3.1 specification plus a runnable mock server. The final deliverable is a documented, testable API for a system that never had one.

### Key Features
- Chrome extension (Manifest V3) that intercepts and logs XHR/fetch traffic from any tab
- Backend that deduplicates requests, infers path parameters (e.g., `/users/{id}`), and clusters response schemas
- Claude API call to auto-draft prose descriptions for each discovered endpoint
- Generated OpenAPI spec rendered in a Swagger UI viewer
- Mock server (FastAPI) that replays captured responses so teammates can develop against the API without hitting the real system

### Suggested Tech Stack
Chrome Extension (Manifest V3, TypeScript), Python/FastAPI (mock server + clustering logic), React + Vite (management UI), Claude API (endpoint description generation), Supabase (spec storage)

### Why It's Interesting
Students learn HTTP internals, API design principles, and reverse engineering from the outside in: starting with real network traffic and working backward to a clean specification. The output is a tool they can actually use in future projects, and the problem mirrors what many developers encounter in industry when dealing with legacy systems.
