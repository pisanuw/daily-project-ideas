# Project Ideas for 2026-05-22

## 1. Agent State Sketcher
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** [Show HN: Statewright – Visual state machines that make AI agents reliable](https://news.ycombinator.com/item?id=48108778)

### Description
A browser-based drag-and-drop tool where you design AI agent state machines visually using flowchart nodes, then click "Run" to watch the agent execute against sample inputs with an animated step-by-step trace. The tool also generates a working Python or TypeScript agent scaffold from the diagram, closing the gap between whiteboard design and runnable code.

### Key Features
- Drag-and-drop node editor with typed transitions (tool calls, LLM decisions, loops, error handlers)
- Live animated execution trace showing which state is active and what data flows between nodes
- One-click export to a Claude API agent skeleton in Python or TypeScript

### Suggested Tech Stack
React, React Flow, Vite, Tailwind, Claude API

### Why It's Interesting
Visual state machines are the clearest way to reason about agent reliability, yet almost no tools let you go from diagram to running code instantly — this fills that gap for anyone building agents.

## 2. Knowledge Gap Mapper
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** [Top AI GitHub Repositories Dominating 2026 – personalized curriculum AI trend](https://medium.com/lets-code-future/top-ai-github-repositories-that-are-dominating-2026-and-you-also-need-to-know-about-that-970ce6a61b96)

### Description
Students answer a short adaptive quiz on any CS topic the instructor sets up (sorting algorithms, recursion, networking, etc.), and the app generates a visual dependency graph coloring mastered concepts green, shaky ones yellow, and unvisited gaps red. Instructors get an aggregate class-level heat map so they can see in one glance which prerequisite concepts most students are missing before a lecture.

### Key Features
- Adaptive quiz generation via Claude API that adjusts difficulty based on each answer
- Interactive concept dependency graph per student (nodes are concepts, edges are prerequisites)
- Instructor dashboard showing class-wide aggregate heat map with drill-down per student

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Claude API, Supabase

### Why It's Interesting
Knowledge gaps in CS courses are usually invisible until the midterm; this makes them visible and actionable for both students and instructors in under five minutes.

## 3. Security Escape Room
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** [Hack the AI agent: Build agentic AI security skills with the GitHub Secure Code Game](https://github.blog/security/hack-the-ai-agent-build-agentic-ai-security-skills-with-the-github-secure-code-game/)

### Description
A gamified web app where students work through a series of locked "rooms," each containing a deliberately vulnerable Flask and React mini-app. They must identify and patch the vulnerability (SQL injection, XSS, CSRF, broken authentication) to unlock the next room, with an AI hint system that gives structured clues without revealing the answer. Instructors can author new rooms by submitting a vulnerable code snippet and a patch, and the app auto-generates the quiz metadata.

### Key Features
- Progression-locked rooms each themed around a single OWASP vulnerability category
- AI-powered hint system (Claude API) that escalates specificity across three hint levels without ever giving the full fix
- Automated room validation using unit tests and lightweight static analysis so students get instant pass/fail feedback on their patches
- Instructor room authoring tool: paste vulnerable code, paste the fix, and the app generates the room scaffolding

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase, Claude API, Bandit (Python static analysis)

### Why It's Interesting
OWASP vulnerabilities are notoriously hard to teach from slides alone; framing them as escape room puzzles forces students to think like attackers before thinking like defenders, which dramatically improves retention.
