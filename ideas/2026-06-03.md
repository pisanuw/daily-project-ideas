# Project Ideas for 2026-06-03

## 1. Changelog Storyteller
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** [Show HN: Git for AI Agents](https://news.ycombinator.com/item?id=48063548) and the broader trend of making git history more human-readable

### Description
A CLI and lightweight React web app that takes a git revision range (e.g., `v1.2.0..v1.3.0`) and uses Claude API to synthesize all commit messages, PR titles, and changed file paths into a polished, multi-format changelog. The user picks an output style: classic CHANGELOG.md, a tweet thread, a blog post intro, or an executive summary for non-technical stakeholders.

### Key Features
- Accepts a git revision range or two tag names as input
- Clusters commits by type (feat, fix, docs, refactor) automatically
- Renders output in four selectable formats: CHANGELOG.md, tweet thread, blog post, executive summary
- Optional: Claude annotates which changes are user-facing vs. internal

### Suggested Tech Stack
React + Vite + Tailwind for the web UI, Flask + GitPython for the backend, Claude API (claude-sonnet-4-6) for synthesis

### Why It's Interesting
Writing release notes is tedious and often skipped; this makes it a 30-second task. It also teaches developers how AI can bridge the gap between raw version control data and human communication.

## 2. Rubric Calibration Bench
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** Ask HN threads on AI grading reliability and the recurring professor complaint that AI rubrics drift inconsistently across submissions

### Description
A web tool where professors upload 10-20 sample student submissions alongside their intended scores, then run Claude against them using the current rubric. The app visualizes agreement vs. disagreement as a scatter plot, highlights which rubric criteria caused the most variance, and suggests specific rubric wording changes to improve consistency. Professors iterate until calibration reaches an acceptable threshold before deploying the rubric for real grading.

### Key Features
- Upload submissions (PDF, plain text, or code files) with instructor-assigned reference scores
- Run Claude grading pass with the current rubric and display a score comparison table
- Disagreement heat map showing which criteria are most inconsistent
- One-click rubric edit suggestions generated by Claude based on identified failure patterns
- Save rubric versions and compare calibration scores across iterations

### Suggested Tech Stack
React + Vite + Tailwind frontend, Flask + Supabase backend, Claude API for grading and rubric improvement suggestions

### Why It's Interesting
AI grading is only trustworthy when the rubric is well-calibrated; this closes the feedback loop that is currently missing from most AI-grading workflows, making it a genuine force multiplier for large classes.

## 3. LLM Behavior Observatory
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** [Show HN: Statewright - Visual state machines that make AI agents reliable](https://news.ycombinator.com/item?id=48108778) and the awesome-ai-agents-2026 repositories emphasizing the need to understand model behavior before building reliable agents

### Description
Students build a systematic experimentation platform to study how an LLM behaves across a domain of their choice (e.g., math word problems, code debugging, ethical dilemmas). The platform runs batches of prompt variants across temperature and system-prompt configurations, records all outputs, and renders an interactive dashboard of findings: consistency scores, failure modes, surprising outputs, and a publishable findings report generated by Claude.

### Key Features
- Define experiment suites: a task domain, a set of prompt variants, and parameter ranges (temperature, top-p)
- Batch-run experiments against Claude API or Gemini API and store results in Supabase
- Interactive dashboard: consistency heatmap, sample failure/success outputs, statistical summaries
- Auto-generate a structured findings report (intro, methodology, results, discussion) using Claude
- Export results as a shareable JSON dataset for peer comparison

### Suggested Tech Stack
React + Vite + Tailwind + Recharts for the dashboard, Flask + Supabase for experiment storage and batch execution, Claude API or Gemini API as the model under test

### Why It's Interesting
Students come away with both a reusable research tool and genuine empirical findings about LLM behavior, which is exactly the kind of portfolio project that stands out to employers and prepares them for AI engineering roles.
