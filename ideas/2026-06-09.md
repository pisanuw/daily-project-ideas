# Project Ideas for 2026-06-09

## 1. Claim Grounding Lens
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** [Show HN: Git for AI Agents](https://news.ycombinator.com/item?id=48063548) and the AI accountability/hallucination reliability trend in 2026

### Description
A browser tool where you paste an AI-generated response alongside a ground-truth source document (article, paper, or docs page). Claude highlights each factual claim in the AI response as "grounded" (green), "unsupported" (yellow), or "contradicted" (red), quoting the relevant source excerpt for each verdict. Built for journalists, researchers, and educators who want to show students exactly where AI makes things up.

### Key Features
- Side-by-side diff view: AI response on the left, source document on the right
- Color-coded claim annotations with quoted evidence from the source
- Summary card showing percentage grounded, unsupported, and contradicted
- Shareable report link for classroom review

### Suggested Tech Stack
React, Vite, Tailwind CSS, Claude API (claude-sonnet-4-6)

### Why It's Interesting
Hallucination detection is the most requested real-world AI safety capability, and this weekend-sized version is immediately classroom-usable: instructors can visually show students where an AI-assisted essay drifted from the source material.

## 2. Assignment Load Estimator
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** [Ask HN: What are you working on? (May 2026)](https://news.ycombinator.com/item?id=48085993) and HN discussion on calibrating coursework difficulty as AI tools change how long tasks take

### Description
An instructor-facing tool where you paste or upload an assignment spec (PDF, Markdown, or plain text). Claude estimates realistic completion time for three student skill tiers (beginner, intermediate, advanced), identifies the top three conceptual hurdles students are likely to hit, and generates a bulleted scaffolding plan to ease the hardest parts. Helps professors avoid over- or under-loading students in an era where AI copilots compress some tasks and expose others.

### Key Features
- Upload or paste assignment spec (PDF, Markdown, or plain text)
- Per-tier time estimates with plain-English reasoning
- Annotated list of the hardest concepts with suggested teaching interventions
- Exportable scaffolding plan as Markdown or PDF

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Claude API, PyMuPDF for PDF parsing

### Why It's Interesting
As AI coding tools quietly change how long assignments take, professors have lost their calibration instincts — this gives them a fast, explainable second opinion before the assignment goes live.

## 3. NPC Dialogue Architect
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** [GitHub Blog: Beyond the engine — 10 open source projects shaping game dev](https://github.blog/open-source/gaming/beyond-the-engine-10-open-source-projects-shaping-how-games-actually-get-made/) and NVIDIA's investment in the open-source Godot engine

### Description
Students define a game character (name, personality traits, backstory, faction, key relationships) as a simple YAML config file. A Flask + Claude API pipeline generates a full branching dialogue tree in Ink script format, ready to import directly into Godot 4. A React dashboard lets students preview the tree visually, regenerate individual branches they dislike, and export to both Ink and a plain JSON format. Teaches AI-assisted narrative design, API pipeline construction, and game engine integration in one project.

### Key Features
- YAML character spec to Ink dialogue tree via Claude API
- React tree visualizer with per-node branch preview and inline editing
- One-click Godot 4 compatible export (.ink and .json)
- Iteration mode: lock approved branches and regenerate only the rest

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Claude API, Godot 4 (for integration demo), Ink scripting format

### Why It's Interesting
Bridging AI text generation with a real, industry-used game engine gives students a complete end-to-end pipeline project with a tangible, playable deliverable, and Ink + Godot is a legitimate production stack.
