# Project Ideas for 2026-06-11

## 1. Devcontainer Sketch Pad
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** `apple/container` trending on GitHub (June 2026) - a tool for running Linux containers via lightweight VMs, and the perennial classroom problem of students spending week 1 fighting environment setup instead of coding

### Description
A visual drag-and-drop designer for `.devcontainer` configurations. Pick language runtimes, databases, ports, and VS Code extensions from a palette, preview the live-generated `devcontainer.json` and `docker-compose.yml`, then export or share via a URL-encoded link. Professors can share a single URL that gives every student an identical, ready-to-run dev environment.

### Key Features
- Visual palette of common services (Node, Python, PostgreSQL, Redis, MongoDB, etc.)
- Real-time preview of generated devcontainer.json and docker-compose.yml
- Shareable URL that encodes the full config in the hash (no backend needed)
- Curated template library for common course setups (web dev, data science, systems)
- One-click "Download .devcontainer folder" export

### Suggested Tech Stack
React, Vite, Tailwind (pure client-side - config encoded in URL hash, no backend required)

### Why It's Interesting
It eliminates the "it works on my machine" problem on day one of a course and gives CS professors a practical artifact to share, making containerized environments accessible to students who have never touched Docker.

## 2. Code Review Council
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** `msitarzewski/agency-agents` trending on GitHub (specialized expert agents with distinct personalities) and `kenn-io/agentsview` (session intelligence for coding agents) - the idea of multiple focused agents reviewing the same artifact

### Description
Submit a code snippet and watch a panel of AI reviewer "characters" critique it simultaneously from different angles: a Security Auditor finds injection risks and unsafe patterns, a Performance Engineer spots bottlenecks, an Accessibility Checker catches a11y violations, and a Confused Junior Dev asks clarifying questions. Each reviewer has a distinct system prompt and personality, and their feedback appears side-by-side with inline annotations.

### Key Features
- 4-5 distinct AI reviewer personas (security, performance, accessibility, readability, junior perspective)
- Side-by-side panel showing each reviewer's prioritized feedback
- Inline code annotations linking feedback to specific lines
- Classroom mode: instructor can define custom reviewer personas per assignment (e.g., "OWASP Top 10 Checker" for a security course)
- Export full review session as a markdown report

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (parallel requests with distinct system prompts per persona), Supabase for session storage and classroom sharing

### Why It's Interesting
It shows students concretely what multi-perspective professional code review looks like and trains them to internalize multiple lenses before they write code - not just "does it work" but "is it safe, fast, readable, and maintainable."

## 3. Constraint Dungeon
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Trending discussions on creative constraint-based learning and game-based CS education; distinct from competitive code golf - the focus is on forcing conceptual understanding by removing familiar tools

### Description
A puzzle game where players solve programming challenges under creative constraints: sort a list without comparison operators, implement a calculator using only bitwise ops, reverse a string without slicing or indexing. Each "room" of the dungeon adds a new constraint layer on top of previous ones. An AI generates fresh puzzle variants, validates solutions against the constraints, and gives Socratic hints - never the answer, always the next question.

### Key Features
- 20+ built-in constraint categories (no loops, no conditionals, no built-in methods, line limit, memory limit)
- AI-generated puzzle variants to prevent copy-pasting solutions
- Multi-language support (Python, JavaScript, Java, C++) via sandboxed code execution
- Per-student progress map showing which constraint rooms are conquered
- "Hint dungeon": the AI asks questions that guide students toward the insight without giving it away

### Suggested Tech Stack
React, Vite, Tailwind (frontend), Flask (backend), Supabase (user progress, leaderboard), Judge0 API (sandboxed code execution), Claude API (hint generation and puzzle variant generation)

### Why It's Interesting
Constraints force students to reason about language primitives and algorithmic thinking from first principles - a far richer learning experience than standard LeetCode problems, and one where AI is genuinely helpful as a Socratic tutor rather than an answer machine.
