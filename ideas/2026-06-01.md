# Project Ideas for 2026-06-01

## 1. Agent Tripwire
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** https://news.ycombinator.com/item?id=47799856 (Show HN: Runtime security for AI agents - injection, tool abuse, data exfiltration)

### Description
A browser-based tool where you paste an AI agent's tool-call log, define lightweight security rules (e.g., "never read files outside /tmp", "never call URLs not in allowlist", "never pass user data to external APIs"), and instantly get a color-coded violation report. It acts as a post-hoc auditor for agent sessions you didn't write or fully control.

### Key Features
- Rule builder with a small DSL: define allowed paths, domains, and data patterns
- Log parser that handles common agent log formats (Claude, LangChain, OpenAI tool calls)
- Violation report with severity levels (warn / block), highlighted log lines, and exportable JSON

### Suggested Tech Stack
React, Vite, Tailwind, Claude API (for natural-language rule interpretation), no backend needed

### Why It's Interesting
As AI agents proliferate and get handed off between teams, there is no easy way to audit "did this agent stay in its lane?" -- this fills that gap with a dead-simple drag-and-drop tool.

## 2. Misconception Mosaic
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** General AI classroom engagement research and AI tools for student understanding (edcafe.ai/blog/ai-tools-for-student-engagement)

### Description
After a lecture, a teacher posts one key concept (e.g., "recursion" or "gradient descent") and students each submit a 2-sentence plain-English explanation. Claude clusters all submissions into understanding patterns, surfaces the top 3 misconceptions with representative student quotes, and generates a targeted one-slide micro-lesson for each. The teacher gets a live mosaic dashboard showing the distribution of understanding across the class.

### Key Features
- Teacher dashboard: concept prompt, live submission feed, mosaic heatmap of understanding clusters
- Claude-powered clustering that labels each submission as "on-target", "partial", or "misconception" with the specific error type
- Auto-generated follow-up micro-lesson for each misconception, ready to copy into slides

### Suggested Tech Stack
React, Vite, Tailwind, Flask, Supabase (real-time subscriptions for live feed), Claude API

### Why It's Interesting
Most formative assessment tools tell you who answered but not why they misunderstood -- Misconception Mosaic makes invisible student mental models visible in under 5 minutes after class.

## 3. Source Watcher
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Hacker News project that "monitors various sources for changing information and creates pull requests or email notifications when something changes" (news.ycombinator.com/item?id=48085993)

### Description
Students design and build a fully automated change-detection pipeline: define a set of sources to watch (GitHub trending, an RSS feed, a public JSON API, or an arXiv search query), write an LLM-based relevance filter that decides whether a change is worth surfacing, and wire up a notification output (GitHub PR, email digest, or Slack webhook). The project teaches event-driven architecture, the LLM-as-filter pattern, and responsible automation.

### Key Features
- Source connectors for at least two input types (RSS/Atom feed + GitHub API or public REST API)
- LLM filter step where the student writes a prompt that decides relevance (and must document the prompt and its failure modes)
- Notification output with rate-limiting and a "dry run" mode that logs what would have been sent

### Suggested Tech Stack
Python, Flask or FastAPI, Supabase (for storing seen items and trigger state), Claude API or Gemini API, APScheduler or cron for scheduling, GitHub API or SMTP for output

### Why It's Interesting
Building a real pipeline that runs unsupervised forces students to think about failure modes, prompt reliability, and side-effects -- exactly the skills needed for production AI work.
