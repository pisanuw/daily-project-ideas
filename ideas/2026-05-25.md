# Project Ideas for 2026-05-25

## 1. Ollama Arena
**Category:** Side Project
**Complexity:** Weekend
**Inspired by:** Ollama crossing 165k GitHub stars and the broader local-first LLM trend in 2026 (https://ossinsight.io/trending/ai), plus Hacker News discussions about comparing model outputs

### Description
A browser-based tool that sends the same prompt to multiple locally-running Ollama models simultaneously and displays their outputs side by side. Users rate each response, and the app tracks personal preference scores over time by task category (coding, explanation, creative writing, summarization), building a personalized leaderboard of which local model works best for which job.

### Key Features
- Simultaneous multi-model prompting via the Ollama REST API (no API key needed)
- Side-by-side response comparison with a 1-5 star rating per response
- Task category tagging so ratings accumulate into a per-category leaderboard
- Export session results as JSON for further analysis

### Suggested Tech Stack
React, Vite, Tailwind CSS, Ollama local API (http://localhost:11434), localStorage for persisting ratings

### Why It's Interesting
Local LLMs are now mainstream but there is no easy way to empirically compare them on your own use cases. This fills a genuine personal productivity gap and is completable in a single weekend with zero cloud costs.

## 2. AI Observation Journal
**Category:** Teaching Tool
**Complexity:** 1-2 Weeks
**Inspired by:** 2026 trend of 67% of school districts adding AI literacy to curriculum (https://www.facultyfocus.com/articles/teaching-with-technology-articles/designing-the-2026-classroom-emerging-learning-trends-in-an-ai-powered-education-system/), and the need for structured hands-on empirical methods for teaching AI behavior

### Description
An instructor creates structured "AI experiments" in a dashboard: a prompt, a chosen model, and a set of observation prompts (e.g., "Did the AI hallucinate a fact? Did it reflect a demographic bias?"). Students run each experiment, log their observations in a structured form, and the class builds a shared, searchable "field guide" to real AI behaviors discovered through first-hand observation.

### Key Features
- Instructor dashboard to author experiments with guided observation questions
- Student experiment runner that calls the Claude or Gemini API and captures the raw response
- Shared class observation feed where entries are tagged by behavior type (hallucination, bias, refusal, etc.)
- Simple summary view showing which behavior types the class has observed most

### Suggested Tech Stack
React, Vite, Tailwind, Supabase (shared class data and auth), Claude API or Gemini API for running experiments

### Why It's Interesting
Most AI literacy curricula are lecture-based. This tool turns AI literacy into an empirical lab science where students discover AI limitations through direct experimentation, which produces much deeper understanding than reading about them.

## 3. Adaptive Hint Engine
**Category:** Classroom Assignment
**Complexity:** Multi-week
**Inspired by:** Trending AI gamified learning platforms in 2026 (https://www.disco.co/blog/ai-tools-for-gamified-learning-2026) and the gap between "AI tests your game" vs. "AI helps your player inside the game"

### Description
Students build a browser game (any genre: puzzle, platformer, quiz) and integrate a Claude API-powered hint system that observes serialized game state (score, level, failed attempts, player position) and generates Socratic hints rather than direct answers. The assignment teaches both game development fundamentals and real-time AI integration, culminating in a playable game where the AI co-pilot adapts its hints to how the player is actually struggling.

### Key Features
- Game state serialization: students define a JSON schema that describes their game's current state
- Hint engine API endpoint (Flask) that receives game state and returns a Socratic hint from Claude
- Hint history panel in the game UI showing the conversation between player and AI
- Assignment rubric component: students write a reflection on how they designed the prompt and what they learned from observing hint quality

### Suggested Tech Stack
Phaser.js or plain HTML5 Canvas for the game, Flask + Claude API for the hint backend, React or vanilla JS for the game UI wrapper

### Why It's Interesting
This assignment sits at the intersection of two things CS students need to learn: game development and practical AI API integration. The Socratic constraint on the hint engine also forces students to think carefully about prompt engineering and AI pedagogy, not just plumbing.
